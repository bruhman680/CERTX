# Local seasonal detection, pre-outcome plan

Question: can a Garden cell identify an exogenous season change from **its own resource, its immediate resource neighbors, and its own previous action**, without receiving the global season schedule? To avoid conflating detection with adaptation, all environments continue a fixed `.51` action rule; detection only records labels, it does not intervene.

World uses 16×16, seeds 41160–41171, 6,000 ticks, regrowth `.06` for ticks 1–1500 and 3001–4500, `.048` for 1501–3000 and 4501–6000, otherwise original physics. Each cell observes immediate neighbor resources, its own resource and last action. A model-based residual detector uses known diffusion `.08`, consumption `.18` coefficients and an estimated regrowth quotient, then EMA of the quotient (rate .02), with phase threshold `.054`. Comparison sensor cases: noiseless resource, independent Gaussian-noise resource observations SD=.01 and SD=.03 (clipped to [0,1]). A naive raw-resource detector labels scarcity if local resource below `.48`; a schedule-blind parity sham labels alternating seasons every 1,000 ticks independent of true change points. The residual detector is **privileged with exact known physical coefficients**, though not the season times; state this limitation explicitly.

Compute per-cell classification accuracy after warmup t100, transition-window accuracy for first 250 ticks after true boundaries (1501, 3001, 4501), independent per-seed means, and phase detection delay: first tick after boundary when >60% of cells predict the correct phase for 10 consecutive ticks. No neural learning, no baseline policy changes, no canonical checkpoint use.
