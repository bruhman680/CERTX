## Precise implemented scope

Recovered `transformer_context_swap_probe.py` freezes model weights operationally via eval mode and no-gradient forward calls. It constructs oak/elm color-assignment swaps, identical restored text and an `oak:` suffix. Source lexical counts match, but tokenizer IDs were never obtained here. The source asserts common token length and single-token encoding of each candidate, but does not assert identical token histograms or identical restored IDs. Its two unrestricted `from_pretrained` calls permit asset downloads. `manual_seed` is not a sampling experiment.

For every prompt, the full path calls `model(input_ids, use_cache=False)` and selects last-position logits. The cached path evaluates all but the final token, then evaluates the last token with that prompt's own past keys/values. No cache transplant, cache deletion, cache corruption, context eviction or generated-action write is performed. In GPT-2's expected default handling, the cached last token receives position equal to past length, agreeing with full-prefix last position; however positions and masks are implicit, not logged/asserted. Equal length across contexts controls final absolute position but does not control intervening lexical token positions, which are the intervention. No padding is introduced; lack of an attention mask therefore is not itself an established failure. Runtime-specific implicit position/cache conventions remain unverified.

The sole numeric assertion requires maximum vocabulary logit difference between cache/full paths to be strictly below 1e-3 for each of three prompts. This is an absolute tolerance, with no relative tolerance, dtype/runtime identity, per-token diagnostics or downstream margin check. It establishes neither bitwise equality nor a uniform result across other models, prefixes, precisions and horizons. NaN discrepancies would fail the comparison. Restore delta is printed but never asserted; context-effect magnitude/sign is printed without an acceptance criterion. The declared `log_odds` is raw logit difference. It equals log probability ratio at temperature 1; at temperature T the actual log probability ratio is the difference divided by T.

Temperature values 0.5, 1 and 1.5 are applied after each model call with `softmax(logits/T)`. No temperature parameter enters that call. It follows algebraically that these rescalings leave the already-computed raw logits and attention unchanged at this fixed prefix. The printed label `sampling_probabilities` describes probabilities, not sampled tokens. No attention tensors, sampled continuations, seed sweeps, deletion controls or multi-step temperature-induced prefix divergence are implemented. At later generated steps temperature can indirectly alter attention through a changed sampled prefix; this does not contradict fixed-prefix separation.

## Executed algebra and decision sensitivity

For synthetic logits [2,-1,0.4,0.4], the blue/green analogue's log probability ratios are 6,3,2 at T=0.5,1,1.5. The harness asserts the exact identity within 1e-12, sum-to-one, preserved raw input, preserved argmax, and additive-shift invariance. A separate synthetic attention score vector is held fixed; that illustrative unchanged value is not evidence about model attention. All assertions passed.

A synthetic near-tie demonstrates a real limitation of the source tolerance: full logits [0,1e-5] and cached logits [2e-5,1e-5] differ by only 2e-5, passing 1e-3, yet have different argmax tokens. More generally a vocabulary max error epsilon bounds pair-logit-difference error by 2 epsilon and temperature-scaled log-ratio error by 2 epsilon/T. Raw-logit agreement alone cannot guarantee decisions near a tie. The source prints candidate probabilities rounded to eight decimals, so future comparisons should use serialized unrounded quantities.

## Surviving relationship, rival and translation boundary

The intact-prefix cache/full square is useful: token prefix maps by full recomputation or prefix-cache plus final-token evaluation into vocabulary logits; max absolute discrepancy is its witness. It tests two routes computing one input. It does not test a persistent field changed by an autonomous action. Temperature belongs to a subsequent map from logits to probability simplex, not the cache intervention. No cube or cache-to-field mechanism is empirically justified by current unexecuted model vertices.

Ordinary positional, prefix-conditioned language modeling is the serious rival to a stronger action-written wake. A future oak/elm effect could reflect induction, lexical associations or position-sensitive pattern completion; this two-context probe does not isolate these mechanisms. Identical restored text is a deterministic implementation control, not evidence that a model remembered prior exposure. Attention concentration would not establish causal storage, trapping or an absorbing repetition state even if subsequently measured. The proposed field-wakes note correctly distinguishes those stronger experiments from this source's narrower implementation.
