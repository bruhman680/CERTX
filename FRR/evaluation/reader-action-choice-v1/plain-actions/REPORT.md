# A word interface exposes the next gap

Outcome-informed follow-up after 0/32 strict valid letter replies from each router. The letter results remain unchanged.

With plain action words and a permissive complete-leading-word parser, the adapted model returns 16/16 exact commands, all YES or NO. It answers YES for every forward menu and NO for every reversed menu, across all eight distinct visible observations. The original gives six recognized YES prefixes out of sixteen, all menu echoes; no exact-word replies. Neither free router requests FULL or TARGET. Forced word selection also uses only YES/NO. A recognized command is therefore not evidence of an adaptive request policy.

32 actual new action probes produce 192 logical routes across two models, two orders, free/forced decoding and 24 scenarios. Archive retrieval functions execute when requested; identical fixed-worker responses are reused from the main contact and never counted as new inference. The six action words have unequal lengths, so forced summed scoring has a vocabulary/length limitation.
