## What this establishes

The observation interventions changed the actual input token sequences: all three input hashes differ, while the output text is identical. The before and after factual prompts also have the same token count, so their difference is not simply a different input length. That does not isolate numerical semantics: they still contain different token identities and come from selected snapshots.

This narrows the previous literal constant-input explanation. Here the inputs differ, yet these particular measurements do not change the observed greedy next reply. It would be inaccurate to claim that the experiment remained an exact-input fixed point. It would also be inaccurate to infer that the model cannot perceive or internally represent the values, ignores every possible observation, or has no environmental competence. Those are stronger claims than the visible mapping supports.

The free-writing condition contains no task whose correct action depends on the counts, so an unchanged action is not automatically an incorrect policy. The separate prompted retrieval contact asks a different, more specific question. Observation availability, a changed internal state, a changed output and a useful executed action remain distinct evidence layers.

The label-only versus factual prompts differ in content and length. There is one deterministic call per selected prompt, no statistical treatment estimate, and no long-run feedback cycle. The old no-observation greedy output is retained earlier evidence, not a fresh replication in this experiment. No observation policy is adopted into the main garden, which remains preserved separately.
