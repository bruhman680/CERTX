## How this sharpens the present tests

These are inferences from the sources and our declared protocol, not new published results:

1. **State discrimination is layered.** Two saved worlds can differ while the selected text input is identical. Supplying measured facts can make the inputs distinguishable. If the resulting action stays the same, that demonstrates only the observed input/output mapping; it does not prove that the model failed to perceive or internally represent the facts.
2. **An observation need not demand a new action.** The garden is not optimizing a stated task reward. A free-writing reply that stays similar after a changed file count is not automatically an incorrect policy. A direct retrieval task is therefore a separate diagnostic with a specific observable answer, not an obligation added to the main run.
3. **Availability, access and use require separate evidence.** A world-readable file, a model-issued read, a returned value, and a value-correct response are different events. The hidden-value pair tests should retain which event actually occurred. A supplied-read control is operator-provided information and must not be relabelled spontaneous retrieval.
4. **Variation needs a consequence check.** Changed sampled text can break an exact repeat loop without producing a useful executable action. Retain all seeds, raw text, fence status and actual receipts. Do not select the most attractive sample and claim that the source model improved.

The strongest practical contribution is a cleaner decomposition of the evidence. No memory selector, sensing cue, instruction sequence or decoder setting is adopted merely because an older source discusses a related concept. Numerical snapshot inputs and explicit tasks remain labelled interventions on detached copies.
