# Scout convening

User explicitly requested an FRR-harnessed scouting swarm. Three agents were spawned: scout_causal_memory, scout_prediction and scout_agent_memory. Root independently searched broad leads and inspected Causal Memory Policy methods/limitations. Scouts read primary texts rather than counting search snippets as support.

Operational brief: identify observable/intervention/claim forward; trace assumptions and provenance backward; test a rival and transferable control laterally. The full FRR runtime was not separately installed as a new software harness, and adherence/effectiveness was not measured. This was a role-separated inquiry brief informed by the existing FRR context.

Root shared agent-memory paper leads and the CMP candidate-pool limitation; the readings are coordinated, not independent replications. No new experiments, agent task trials, deployments or external communications were performed. Same model/platform lineage and shared repository access remain limitations.

Converging recommendation: vary intervention diversity versus precision; allow equivalence-class outcomes; use an observed-history predictive comparator; distinguish stationary hidden movement from real drift; bridge to independently scored actions and selective repair. Root synthesized and prioritized the proposals; agreement does not itself validate them. All ten sources have explicit read-depth/provenance in SOURCES.json.
