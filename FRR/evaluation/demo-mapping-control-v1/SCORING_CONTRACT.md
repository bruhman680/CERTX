# Frozen scoring contract: demonstration mapping control

Scope: nine authored threshold questions, three prompt arms, 27 deterministic branches from one fixed model. Gold follows the actual target records and the at-least threshold relation, inclusive of equality. UNKNOWN is the required outcome for a missing target measurement, as explicitly requested in the generation instruction. Deliberately permuted demonstration answers do not change actual task gold. These are exposed development questions, not an independent held-out population.

Root and an arm-masked reviewer independently code generated text; preserve both initial deposits before comparison. Reviewer packet contains shuffled ID, target records/question/gold and generated text, not condition, demonstration labels, prompts or root scores. Shared storage masking is instructional and style may reveal arms. Separate scoring judgment is not independent scientific replication.

## Fields and operational rules

- `surface_label`: literal leading YES/NO/UNKNOWN (case-insensitive), or NONE; AMBIGUOUS for incompatible unqualified answer labels. This is a syntax observation and may belong to an echoed demonstration rather than the target.
- `explicit_decision`: YES/NO for an unambiguous target-directed acceptance/rejection, including a leading label used to answer the task; UNKNOWN for an explicit target-directed cannot-determine/unknown/insufficient-information answer. NONE if absent or response addresses only another entity/task. AMBIGUOUS if incompatible final task decisions remain unresolved. A generic conditional rule is not an explicit task decision.
- `status`: evidence-sensitive task status. Start with `explicit_decision` when a task-directed decision exists. Without one, a case-specific acknowledgment of the absent required target measurement counts UNKNOWN. Bare numeric restatement or a generic conditional rule counts AMBIGUOUS; do not supply the comparison on behalf of the model.
- `explicit_match` and `status_match`: equality of the respective field to the frozen gold. Labels on an unrelated demonstration receive no task match, even if surface direction equals gold.
- `fully_warranted`: status matches gold and no material false explanation, invented target measurement, incorrect criterion, wrong source/entity or unjustified comparison appears. A clear bare correct decision may qualify when no explanation was requested. A correct direction with false explanation does not qualify. An UNKNOWN explanation, when provided, must identify the actual missing measurement rather than unrelated missing data. A concise case-specific missing-measurement acknowledgment may qualify without literal UNKNOWN.
- `target_mismatch`: answer addresses a demonstrated or unrelated entity/task instead of the actual target. For a pure wrong-entity response, retain surface label but set explicit_decision=NONE and status=AMBIGUOUS. An answer about the actual target using fabricated measurements is an explanation/source error and is not automatically target mismatch.
- `example_echo`: substantive copied demonstration entity/quantity/block, with an explanatory span in the rationale when detected. YES/NO/UNKNOWN alone never establishes echo because those are the intended answer vocabulary. A generic repeated threshold relation alone is not an example echo.
- `generic_rule_echo`: answer recites instructions or a generic conditional comparison rule without applying it to the actual target. Can coexist with an eventual task decision if output includes both.
- `material_error`: additional false/unsupported factual, source or criterion claims. Do not count a bare unsupported YES/NO on a missing-measurement case here unless it also adds a false or fabricated explanation.
- `unsupported_certainty_missing_evidence`: task-directed YES/NO on a target with no measurement. This is separate from `material_error`; BOTH are true if the answer also invents a measurement or false rule. Never blanket-clear material_error when this flag is true.
- `rationale`: short justification and any ambiguous reading/sensitivity; preserve unresolved reviewer disagreement rather than silently repairing labels.

Record stop reason and token cap from the execution manifest separately. EOS does not certify semantic completion; truncation does not mechanically determine semantic score. Leading labels followed by an explanation about the actual target retain their direction even when the explanation is false; false explanation invalidates full warrant. Where the entire answer is another demonstrated task, apply the wrong-entity rule instead. Truthful copied premises can still be an incomplete answer.

## Reporting

Report per-arm task-status matches, explicit-decision matches and fully warranted answers separately, alongside wrong-target/example/rule echoes, false claims and unsupported certainty. For the matched-length correct/permuted pair, expose per-item text/decision transitions, including unchanged and ambiguous outputs. A task-directed answer matching a cyclically permuted gold label is a descriptive relation only, not proof of abstract mapping induction. Fewer echoes do not imply greater correctness. The no-example arm has fewer tokens/information and is not an equal-budget causal control.

Do not infer general FRR benefit/harm, permanent learning or a neural mechanism. Do not tune prompts, rerun failed semantic trials or alter keys after seeing outcomes. Any coding correction should append a reconciliation/correction artifact retaining initial deposits and the frozen contract.
