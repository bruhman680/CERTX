# REV-C1: continuing a corrected research history

Prospective exploratory comparison requested by user: run ordinary fresh agents, then the same tasks with new agents carrying an FRR base. Two fictional cases, two fresh context replicates per case per condition, eight trajectories and two turns each: maximum 16 participant turns. Two additional new reviewers, one response each, score anonymized output pairs: maximum 2 reviewer turns. Two preceding design contexts authored cases and rubric; these are separate preparation, not behavioral samples. Stop at these caps with no outcome-driven retries or added cases.

A case author began with fork_turns=none, no repository access and no FRR treatment text. Parent preserved its two fictional histories and evidence updates in CASES.json and adopted a separately suggested rubric. Shared underlying model ancestry and designer treatment awareness remain; separately drafted does not mean independent scientific confirmation or reserved benchmark. The cases are closely related revision problems, not two independent research populations.

Ordinary guidance is the frozen competent common task instruction. FRR adds prompts/compact.md verbatim, operational compact runtime 0.2, only on the first turn. No handoff/current research map/old experiment outputs supplied to participants. The same context receives the later record on turn two, retaining its initial history and guidance. The comparison tests this guidance bundle with additional input length; there is no matched-length generic arm in this user-requested two-condition run. Core file unchanged.

Within each block case/replicate order is shuffled once, then identically reused. All ordinary first/final responses are collected before FRR participants start, as requested. This introduces a time/order confound and does not support isolating every effect to FRR. All first/final prompts and rubrics are frozen before the first ordinary response; no FRR amendment based on baseline results. New participant contexts use fork_turns=none. Model/effort inherited; exact sampling settings, token/dollar usage and elapsed-time receipts unavailable or not instrumented. Requested 300-word output limit is post-counted, not a hard token cap. Do not call equal turn counts equal compute.

Participants use natural prose, not a fact-certificate template. First memo reconstructs current interpretation from original findings, evidence-backed correction, stale summary and unfinished question. The later evidence supports a new scoped result without validating the old flawed estimate. Second memo should revise the active question while retaining earlier findings/corrections that remain valid and identifying a supported next step. This tests continuation in one two-turn context, not indefinite memory, repeated handoff chains or autonomous GitHub retrieval.

Delivery uses one explicitly authorized initial read of the exact assigned prompt file per participant context. The file contains the complete frozen initial task and guidance. After that load, participant access is only supplied conversation text; further tools, external sources and other-agent communication prohibited. Each reviewer likewise has one authorized read of the exact anonymized review-prompt file, then no further tool access. This adds a delivery step shared by both conditions; actual underlying model inferences can exceed the count of task turns because of file-read tool exchanges. Physical shared filesystem/tool availability is not blocked; access/blinding are instructional and public repository exposure is a limitation. Only those assigned loader reads are permitted. No comprehensive tool-access audit is available; assigned access must not be described as proved isolation. Preserve any reported/visible deviations. Fictional records are not real clinical/education evidence; no real-world recommendations follow from their invented numbers.

Reviewers begin new fork-none contexts after all outputs, see history, later record, authored key, initial and final memos under shuffled J IDs. They do not receive guidance text, condition labels, replicate IDs, hypotheses or trial mapping. Substantive wording is not stripped, so style could hint at condition. Reviewers share model provenance; separate judgments are not independent model replication. Preserve both reviews before comparison. Scores 0–2 on four dimensions: current claim/history, evidence/uncertainty, open-question continuity, next action. Totals 0–8 secondary only. Require brief quotations or missing-element explanations; unsupported claims separate. Do not reward verbosity, explicit FRR terms or merely restating every old number.

Retain reviewer disagreement by dimension and trial. Parent may explain a discrepancy using exact evidence, but no silent score replacement or favorable-condition adjudication. Unanticipated noticings are unscored and optional. Preserve positive, negative, neutral and contradictory observations; absence of novelty is acceptable. Unexpected differences are post-run observations, not retroactive predictions or a way to rescue a failed claim.

Tentative expectation: both conditions may preserve the core corrections; whether FRR changes scope, dormant-question handling, next actions or useful alternatives is open. Ties and harmful overcomplication are admissible. No significance test, general superiority claim, invented confidence numbers or private-reasoning inference. Word counts are descriptive output lengths, not quality or cost. Any parsed/review failure stays in denominators; two planned turns are not permission to retry a failed response.

Freeze CASES, settings, assembly script, protocol and compact-source hashes in manifest; publish before participants. Preserve raw first/final message payloads, exact reviewer packet/prompt, both raw reviews, mapping, checks and report. Payloads copied from final messages by parent are not provider transport exports. The score summarizer is implemented after collection under these fixed dimensions and cannot automatically validate prose judgments.
