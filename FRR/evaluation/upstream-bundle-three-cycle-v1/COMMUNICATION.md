# Swarm roles and communication

User explicitly authorized3cycles and small direct/lateral knowledge scouts. Roles:

- Coordinator: protocol, frozen contract, one execution, selected descriptive slices and deposition.
- bundle_direct_scout:2queries/2primary method readings, no new experiment outcomes; RotatE/ComplEx.
- bundle_lateral_scout:2queries/2primary theory/method readings, no outcomes; Locatello/Ovadia.
- bundle_implementation: fresh context, protocol-only implementation without prior Claude code; no main execution by this role.
- bundle_review: inherited-context prospective static reviewer, then every-ledger metric/aggregate auditor and source interpretation.
- bundle_replay_audit: fresh context, prospective bounded sample audit, no experiment imports; same saved arrays/platform, not external empirical replication.

Scouts exchanged assumptions directly with one another and reviewer. They emphasized supplied relations/structure, explicit codebook versus learned scope, and geometric centres versus probability calibration. Reviewer relayed these to coordinator before outcomes. No source was added merely to make a positive result appear corroborated.

Implementation/reviewer communicated about the omitted exact S formula, metric definitions and reason-specific ABSTAIN aggregates. Initial versions are saved; changes preceded execution. Reviewer approved final code/protocol hashes; root froze15files and executed the fixed main once under180seconds. Implementation did not see prior Claude scripts or choose successful seeds. An additional model role is coding separation, not an independent laboratory.

Replay auditor and reviewer divided checks: saved-array/centre/ranking replay on22prospective rows versus all-row metric/full-aggregate reconstruction. They discussed the two within-top3ordering differences and preserved them. No inputs/outputs were modified to resolve those last-bit order changes. No main rerun or post-outcome tuning occurred.

This is a numerical study, not a behavioral swarm experiment. There are no writer/reader participants or private-reasoning records. Token/compute/account usage are not exposed. Group-reasoning and learned-encoder studies remain proposed; reviews and codebook geometry do not measure their benefits.
