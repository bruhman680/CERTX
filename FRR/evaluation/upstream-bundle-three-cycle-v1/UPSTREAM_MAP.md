# A small observation of a broader bundle

The user's fiber/bundle language can be made useful without asserting a new ontology. A chosen readout maps many complete representations to the same scalar or angle. Its preimage can be called a fiber of that map; a locally trivial topological fiber bundle has not been established. Here the observation is already conditioned on several upstream choices.

| Stage | What this run supplies | What remains open |
|---|---|---|
| Task/source meaning | Labels A/N/U and relevant entity/time | Whether real evidence warrants those labels |
| Encoding | Fixed global/scoped phase conventions | Learning scope or semantic operators |
| Structure | Known separate coordinate blocks | Discovering a stable meaningful decomposition |
| Perturbation | Isotropic synthetic query noise | Real paraphrases, corruptions, correlated failures |
| Readout | Cosine, modulus/angle, real A/B, projection | Which readout suits a deployed task |
| Fitting | Labelled held-out-entity angular centres | Probability calibration or stable adaptation |
| Evaluation | Actual top3 plus status labels | Durable memory, downstream warranted action |

The scouts' primary-method readings support naming these assumptions. RotatE learns relation-specific rotations; ComplEx learns relation-weighted scores with a real expansion. Neither equates a phase with sentence negation. Locatello's unobserved-factor theorem is not a theorem about this known-factor toy, but motivates making the structural prior explicit. Ovadia evaluates probability quality under shift; our angular-centre fitting is not probability calibration. See [direct](scout/DIRECT.md) and [lateral](scout/LATERAL.md) notes for exact read scopes and limitations.

The most useful upstream movement is to vary one declared dependency while preserving matched information and inspecting where a failure first appears. A readout collision can coexist with distinctions in the full vector. A projection can recover a deliberately supplied factor yet discard noise-resistant context. Neither result alone establishes what a learned system intrinsically stores.
