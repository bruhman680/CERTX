# Prospective implementation

`experiment.py` is an independent NumPy/standard-library implementation of PROTOCOL.md. It has not been executed on study data. Only `py_compile` was run. `experiment_INITIAL.py` preserves the initial code before prospective formula/metric/input-freeze corrections; it is not the approved executable.

Run after approval with `python experiment.py --output-dir NEW_DIRECTORY`. Omitting the argument creates a timestamped directory under `runs/`. Existing directories are refused. BLAS environment variables are set to one before NumPy import. The fixed grid is not configurable. No fitting uses evaluation labels, no outcome threshold is tuned, and no external packages or APIs are used.

Generation precedes scoring: code/protocol copies and hash manifest, all latent/record/noise arrays and queries, their NPZ hashes and per-query array hashes are written before centre fitting, rankings or metrics. Array hashes use contiguous little-endian complex128 bytes. Gzip ledger uses mtime=0 and no embedded filename. NPZ ZIP timestamps may differ on reproduction; arrays and query hashes provide semantic replay. JSON forbids NaN; absent centres and conditionally undefined metrics are null.

For each seed, SeedSequence(seed).spawn(3) feeds PCG64 default_rng streams for latent vectors, calibration noise, evaluation noise. Latent draw order is 12 entity vectors, two time vectors, one predicate vector, then 12*2 binding vectors, all real Gaussian draws normalized per vector. Calibration entities are global IDs 8–11; evaluation IDs 0–7. Context uses normalized entity+time+predicate. Each noise stream draws all real coordinates then all imaginary coordinates, normalizes each direction, and reuses those directions across ratios, modes and noise amplitudes. Repetitions are consecutive within entity/time. Eta=0 repetitions intentionally duplicate arrays. Noise is added to the A record then queries are normalized.

Query IDs exclude calibration conditions because those conditions reuse actual evaluation arrays. Each immutable evaluation_record_key includes every condition plus query row. This separates constructed evaluation rows from generated arrays and distinct latent claims. Query reuse includes actual hash multiplicities, not merely logical cache counts.

All candidate ranks use stable NumPy argsort with canonical index order on exact score ties. Decoding accepts only normalized products and calibration centres. Gold status and scope enter metrics and the explicitly separate oracle diagnostic only. The full product convention is conjugate(query) dot(record), matching real A+iB. Binding reads the actual noisy block and normalizes it. Missing any centre forces calibration_unavailable; otherwise zero_product takes precedence over ambiguous_centre. U remains a source status and ABSTAIN has index 3 solely internally.

A-reference agreement@1 means top1 retrieved key equals (query entity, query time, A); it does not use predicted labels. The additional decoded_A_at_1_if_relevant metric is conditional and is not stance correctness. Encoded-U recall requires retrieving the relevant U record and decoding U. Oracle stance accuracy evaluates only the known true three records, separately from retrieval metrics.

Controls compare normalized full h with normalized real A+iB, and separately raw h with raw A+iB, modulus and defined phase differences. Direct S retains the published norm-balance factor R, with a zero-energy convention of zero. Top3 discrepancies are recorded, including actual indices and third/fourth boundary gaps; near-boundary counts are retained even without mismatches. No mismatches are patched. Full-condition aggregates and across-seed summaries retain ratio/noise match flags; mode-only descriptive summaries supplement them. No population inference is made.
