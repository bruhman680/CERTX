# Review contract: upstream bundle contact

Review role is prospective protocol/code checking, followed by scoped numerical and interpretation audit. Same-platform inherited-context review is not blinded external replication. No source, gold, candidate implementation or historical record will be silently edited by the reviewer.

Before execution inspect: exact context/binding construction and oracle assumptions; unit normalization; fixed seeds/entity/time/noise/calibration split; complete grid and resource budget; distinction between encoded U and output ABSTAIN; zero-product/centre-degeneracy/tie policy; original versus real-coordinate modulus equivalence; calibration applicability; actual top-k pipeline and joint metric. Request a preserved prospective repair for consequential ambiguities.

After execution inspect: frozen bindings; code paths and representative recorded queries; metric reconstruction from actual retrieved IDs and labels rather than oracle relevance; real/complex agreement within declared tolerance; scope of calibration/mixture drift findings; failures retained. Passing schema or arithmetic checks do not establish semantic truth, learned language capability or agent efficacy.

Interpretation: known disjoint blocks are an explicit upstream structural prior; phase labels are supplied; calibration labels and reference orientation are supervised; repeated noises/entities/conditions are dependent. U represents a prescribed source status, while ABSTAIN represents inability to decode. Do not call either a calibrated probability without an explicit calibration study.
