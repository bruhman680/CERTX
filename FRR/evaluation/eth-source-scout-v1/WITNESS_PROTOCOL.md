# Development witness before execution

Enumerate all Boolean vectors of lengths 4,8,12. Compare two one-row linear maps: sum of bits and binary-place-value weighted sum. Both have row rank one; the first has n+1 realized values, the second 2^n. Check whether each fiber preserves a chosen target: parity or first bit. Count summary preserves parity but mixes first-bit labels in n-1 fibers; binary summary preserves either by retaining the entire vector's identity.

This is a basic exact finite counterexample to rank-alone compression claims and to target-independent sufficiency. It neither checks the ETH theorem nor shows an efficient learned semantic summary. No statistical test or expected behavioral improvement. One local main execution; save hashes, runtime and logs. Examples are authored development material.
