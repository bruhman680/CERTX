## What the model encounters

At the first call it receives only the declared system and mechanical user messages. It does not receive a directory listing, hidden target, observer report, performance rubric or the inherited repeated assistant example. World files—including the old notebook—remain available through lawful actions. Fresh conversational input is not a pristine or empty world and is not the original main's unchanged mental/KV continuity.

Thereafter, every exact assistant reply and actual returned receipt is part of that branch's continuous history. A complete exact column-zero Python/shell fence executes unchanged; other or unfinished text remains writing. Ordinary errors return as consequences. Silent successful notebook storage is not fabricated as an error or supplemented with a hint. A successful cell with empty stdout still has its actual channel/exit/boundary receipt.

Files persist. Each cell's process variables, running processes and temporary directory do not persist; generation KV starts fresh. The model's weights are frozen. No autonomous environment ticks or Markov simulation run merely because a conversational entry advances. The matrices are material within the filesystem, not an implicit moving ecology.

The model can change ordinary world files, including the rule-description file, within existing laws. Such an edit is an event to retain, not a reason to restore the file. Editing that description does not alter the parser/runtime implementation outside its world. Model-written programs can implement further structures using the existing interpreters; success or novelty is not assumed.

## Why this is the smallest useful first comparison

The user wants behavior to develop through interaction rather than be selected by our instructions. This proposal removes the common motivational seed and avoids importing our external categories as assignments. It still states the mechanical interface. Describing a transducer does not make it neutral: chat roles, the fence grammar, error format, history selection and decoder remain causal design choices.

The no-FRR local control must therefore be measured afresh. The old main50 repeats cannot serve as the sole control after changing the common framing and conversation history. No-FRR versus compact FRR measures an added-context bundle. A full-source exposure is a separate bundle with different length, vocabulary and task assumptions, not an equivalent implementation of the compact candidate.

A one-time file manifest could be a useful later observation channel: it would expose names/types/sizes without telling which action to take. It is deliberately absent from minimal M0. Adding it only to the FRR arm would confound perception with FRR; adding it to all arms would define a new common interface with its own control. A sensor packet is not assumed neutral because it contains facts.

## Evidence, inference and open uncertainty

**Established local observations:** the active main contract fixes greedy256/freshKV and a strict complete-fence interface; main50 had identical input/output sequences,50 automatic notebook appends and no complete cells. The512 allowance contact retained the same256-token prefix then emitted EOS, without closure. Earlier fresh-role-shell and merged-layout retrieval conditions produced different behavior, including a correct hidden-file read in one layout. These observations establish sensitivity and locally possible action, not the mechanism of the repeated pattern.

**Design inference:** removing the repeated conversation from every arm permits a cleaner first exposure comparison than giving only FRR a fresh start. Removing the motivational seed eliminates one common behavioral instruction. A shared clean mechanical rule file makes the new coupling easier to inspect. These are design choices, not proven improvements or explanations.

**Still unknown:** whether any arm emits a lawful cell; whether FRR changes more than wording; whether errors elicit self-originated repair; whether persistent artifacts are later accessed or used; and whether any favorable effect transfers. A short pilot can establish exposure, continuity and contrasting outcomes without establishing intelligence growth or durable learning.
