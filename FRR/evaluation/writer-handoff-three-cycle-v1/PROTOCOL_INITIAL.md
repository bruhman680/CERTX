# WH-C1/2/3 prospective protocol

All source facts, four future questions and gold rules are saved before writer calls. Writers receive only SOURCE.txt, a question-independent instruction to preserve useful continuation context, and word cap90 or180. Do not ask for private reasoning. No tools/files/web/other participants. They do not receive questions/gold; these files share a physical workspace, so isolation is instructional. One writer per cap: output differences cannot identify a causal budget effect. Preserve actual outputs, cap violations and factual errors.

Four fresh readers get one actual unedited handoff, the same questions and broad source/scope guidance. Order fixed W90-summary, W180-lookup, W90-lookup, W180-summary. Summary-only gets no original; lookup mode may request ORIGINAL and receives exactly SOURCE.txt once. First response is JSON {request_original:boolean, answers:[{id,answer,basis}]}; second is final JSON answers with source/basis. Exactly2turns per reader; a summary-only reader is told original lookup is unavailable, a lookup reader is told it is available. Parent returns requested source or explicit no-new-evidence only, no coaching or gold. Maximum300words per reader turn. No outcome retries or extra reader calls.

Question truth is fixed, but packet-relative warranted answers can differ if handoff omits evidence. Score factual handoff fidelity separately from sufficiency. A derived exact103litre summary can support Q2 without retaining all arithmetic; N8's old-band pass alone cannot support the changed-band question. A true-but-insufficient handoff is not automatically a false summary. A summary-only lucky unsupported yes/no is not source-grounded completion. Q4 no-count evidence supports unresolved, not a conclusive no unless an actual nonzero count is established. Conclusive Q1/Q2 and grounded Q3/Q4 uncertainty are recorded separately. Grounding can cite meaningful handoff text; don't require source IDs absent from a writer's output.

Review fixed criteria: source facts/relations accurately retained; cap adherence; each question's warrant under actual exposed information; known-task answer; justified unresolved vs unwarranted certainty; requests; two-turn completion and transcript/source bindings. Four final answers per context are clustered, not16 independent participants. Parent authored and scores tasks unblinded; separate reviewer knows source/gold and is not a blinded experiment. Word counts are whitespace counts, not tokens or cost. Same default runtime requested but exact backend settings/compute are not exposed. This is a small authored observation, not a framework comparison, long-memory benchmark or deployed action.

Cycle3 combines source scout, numerical/semantic review and minimal guidance updates. No post-hoc question tuning, reinterpretation of factual error as success, hard-source rewrite or general queue completion. Preserve source-authority assumptions and any missing evidence. No new stochastic simulation or external API model calls. Stop after the three cycles for user review.
