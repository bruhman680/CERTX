# Cycle1: actual question-blind writer handoffs

Two fresh-context writers received the same288-whitespace-word fictional ledger and90/180-word caps. They were not shown the future questions or gold, which were fixed and bound before their calls. Source authority and correction semantics are fixture premises. Instructions prohibited tools, files and other agents; physical access was not separately sandboxed. [Writer prompts](WRITER_PROMPTS.json) and [unedited outputs](WRITER_OUTPUTS.json) are preserved.

The90-cap writer produced78words; the180-cap writer produced186words, exceeding its cap by6. Both outputs were retained without shortening, retries or excluding the longer writer. Whitespace words are not model tokens; dense notation changes that ratio. One writer per cap does not estimate a budget effect.

The separate [writer review](../review/WRITER_REVIEW.md) found that both retain the four fixed future-task bases: current82/80 humidity relation,103litre balance, N8 reading/error range, and unknown D9 entry count with decoding locked. Thus the later original-access contrast does not contain a known omitted-answer rescue case. The compact writer derives useful values without seeing the questions; this is a source/task-specific observation, not a guarantee of future sufficiency.

The longer writer's phrase 'Entry count is unknown, not zero' has lexical risk: context supports unknown rather than measured zero, but a literal nonzero assertion would exceed the source. That ambiguity was recorded before reader outcomes; neither handoff was normalized or coached. Both source fidelity and downstream interpretation remain visible rather than silently awarding perfect factual wording.

Before participant calls, review caught a distinct evaluator fault: the original Q4 asked whether evidence establishes zero, for which 'no' could be warranted, while its gold expected unresolved about the count. [Initial files and repair](../PRELAUNCH_REPAIR.md) preserve this; Q4 now asks about the count itself. No writer outcome informed that wording repair. Source and writer prompts were unchanged.
