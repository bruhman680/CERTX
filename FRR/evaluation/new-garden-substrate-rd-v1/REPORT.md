## What this contact establishes

We can specify a changing environment independently of a learning objective. We cannot infer that adding motion supplies the model with a learning algorithm. Three primary sources help distinguish these mechanisms; an exhaustive local audit catches two misleading substrate choices before integration.

The immediate recommendation is a small detached clock-and-coupling prototype with matched static and changing conditions, followed by mechanics verification. Selecting the actual substrate remains open. Do not spend another long model block on the assumption that time or animation alone will resolve copying.

## Source weave: mechanisms and transfer limits

**Algorithm Distillation — Laskin et al., arXiv:2210.14215v1.** The transformer is trained to predict actions from histories generated by learning algorithms across tasks. It can then adapt through context with deployment weights fixed. This supports a distinction between contextual and parameter learning. It does not demonstrate that our off-the-shelf SmolLM2 already acquired that improvement operator. Read abstract, introduction and method §§3–3.2, not an independent reproduction. [Primary PDF](https://arxiv.org/pdf/2210.14215); [version record](https://arxiv.org/abs/2210.14215). OpenReview access encountered browser verification; arXiv was accessible.

**Alchemy — Wang et al., arXiv:2102.02926v3.** Its symbolic version preserves structured causal transformations while removing navigation and visual complexity. It also retains designed tasks and rewards. We can borrow the separation of state, transition, observation and action, plus externally analysable causal structure, without importing its point-maximization objective. Read abstract, introduction and §§3.1–3.4. [Primary text](https://arxiv.org/html/2102.02926v3). This is neither a task-free emergence demonstration nor evidence about our model's proficiency.

**Lenia — Chan, arXiv:1812.05433v3 / Complex Systems 28(3).** Local convolution, growth and bounded state updates produce autonomous patterns. The catalogue includes interactive evolutionary exploration. Transfer: write down the actual physical update and distinguish its dynamics from an observer model's behavior. Moving patterns alone do not show that a language model learned. Read abstract, introduction and mathematical construction in the published paper, not a replication. [Published PDF](https://content.wolfram.com/sites/13/2019/10/28-3-1.pdf); [version record](https://arxiv.org/abs/1812.05433).

These are selected established contacts, not an exhaustive literature review or a novelty claim. No external code, dataset or model was installed.

## Detached exact audit: two tempting worlds fail differently

`python dynamics_audit.py` enumerates all states; results are in RESULTS.json. No model calls or candidate-world operations occur.

Let C act on an eight-bit periodic ring: each output bit is the XOR of its two neighbors. Algebraically C = L + R over GF(2), where L and R are opposite cyclic shifts.

1. **First order:** x[t+1] = C(x[t]). All 256 states reach zero within four ticks. Counts by first zero tick 0–4 are 1, 3, 12, 48 and 192. Since C^4 = L^4 + R^4 = 0 on this particular ring, apparent activity is guaranteed to vanish. This claim depends on the eight-cell periodic geometry; it is not about every Rule90 lattice.
2. **Second order:** T(a,b) = (b, a XOR C(b)). The inverse is T^-1(a,b) = (b XOR C(a), a). We checked both inverse compositions for all 65,536 states and found 65,536 distinct successors. Nonetheless, every orbit has period dividing eight: exact state counts for periods 1, 2, 4 and 8 are 4, 12, 240 and 65,280. Reversibility prevents information loss but does not guarantee a long or useful exploratory horizon. Algebraically, squaring the block transition matrix twice gives T^4 = I + C^2 T^2; squaring again gives T^8 = I because C^4 = 0.

These are closed autonomous maps, without agent interventions. Actions could change their trajectories, so the audit does not prove they are useless for every purpose. It rejects the stronger assumption that either map alone supplies sustained novelty suitable for our intended long blocks. A longer-period alternative would still need tests for degeneracy and meaningful action coupling. No substitute is silently installed.

## Concrete blueprint for the next detached prototype

Use the existing pretrained body, explicit FRR and literal execution interface as declared factors. Preserve candidate38 as the reference. Any alternate universe receives a new contract and lineage; never rewrite its past or describe it as an unchanged continuation.

A minimal model-independent interface should implement:

    transition(state, explicit_operations, completed_reply) -> state, receipts, tick_record
    observe(state) -> truthful bounded observation

A completed reply, even one containing no executable cell, advances one deterministic logical tick. Pausing advances none. Execute supported cells in order, commit real effects and ordinary errors, then apply exactly one world transition. Keep operation count, reply count and autonomous tick count distinct. A crash must not duplicate an already committed operation or tick. Unsupported expression remains recorded expression; no guessed commands, repairs or automatic notebook writes.

The substrate must be material the model can actually affect through the same bounded computational interface. A changing read-only counter is a weaker condition and should be named as such. All state and effects must remain externally reconstructible. Resource ceilings are world constraints, not correctness judgments. Observations report actual state and execution outcomes, with no analyst score or desired action.

Before choosing a file-backed or other concrete material, settle how deletion, empty content, arbitrary bytes, size changes and malformed data behave. Prefer total physical update functions over semantically grading the model's creations. A law-defined no-op or an actual execution error is acceptable if declared; auto-restoring a preferred object would be an intervention. Reserved paths, path traversal, symlinks, and bounded snapshots require mechanics checks before any new filesystem integration.

**Matched conditions:** same initial physical material, observations, actuator, body, FRR and limits. Static condition uses the identity update; changing condition uses the selected law. Keep tick bookkeeping visible in both. The necessary difference in law text is a context difference and must be acknowledged. If we also add new sensors, material or prompts, the comparison concerns the whole package, not motion alone. One trajectory is descriptive; do not turn dependent replies into independent samples.

**External observation:** retain complete raw records and compact summaries. Distinguish world-only changes, agent operations, errors, artifact creation, subsequent artifact use and relevant changes in expression. These are descriptors, not supplied rewards. Any adaptive zoom is external and must not alter model input or resource allowances without a declared condition change. Continue to stop honestly at context capacity; no silent pruning.
