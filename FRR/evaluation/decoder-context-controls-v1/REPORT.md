## Confidence update

- **High, scoped:** greedy can elicit a clean62-byte answer on this exact supplied-fact task. Sampling effects need to be distinguished from the body's conditional abilities.
- **High, scoped:** neither changing decoding nor omitting the compact FRR prefix elicited the specific observed comparison or requested artifact here. Prefix omission is not an observed remedy for these cases.
- **Moderate hypothesis:** representation comprehension, anchoring to initial descriptive text and action-format elicitation remain plausible bottlenecks. These controls do not determine which is responsible.
- **Unestablished:** that a different world, more open-ended time, a different body or weight training is necessary or sufficient. There is no measured general learning or exploration improvement.

The next strongest controls target the remaining bridges separately: (1) show the same actual before/after bytes in a simpler, lossless byte-value display while holding world/question/body/decoder fixed; (2) compare the existing artifact request with a clear request to use its existing executable-cell interface, without providing source or the observation to write. Those would distinguish sensor interpretation and format elicitation from physical-world design. Do not combine them into one “fix,” silently execute unfenced text or teach a preserved free-world trajectory a corrected solution. If needed, later minimal-context controls can bound conditional capability without claiming to isolate a single semantic mechanism.

No additional call, prefix change in an old garden, source repair or training is queued. The practical lesson is not to add more elaborate prompts by default: separate a clean fact answer, an observed state comparison and an actual operation, then target the unverified bridge.
