# Garden v2 review contract

Reviewer reads prior artifacts and shares parent context/platform. Separate reasoning and scalar enumeration provide checking, not independent laboratory replication or evidence that FRR is superior. Aim is useful discovery, preservation and appropriately scoped correction. Own writes stay under this review directory.

Before conclusions, inspect:

- exact observation alphabet and what unreadable/missing/zero means;
- survival and access dependence: complete-case inference needs its explicit selection assumptions;
- identified set versus a sampled grid approximation, and constructive sufficiency of proposed bounds;
- gate restoration must preserve the information-bearing state if interpreted as an access-only test;
- direct witnesses and conservation assumptions remain stipulated unless actually measured;
- decision usefulness must specify actions, loss, uncertainty set, tie rules and measurement cost;
- value of information versus value of state-changing intervention; observation may be useful without identifying every hidden variable;
- protocols, code and outputs agree; exploratory adaptive cases are not sealed confirmation;
- reported counts distinguish worlds, evaluations, datasets and offline reuse; preserve failed executions and corrections;
- historical reports and raw data remain unchanged, current maps are navigation;
- no no-harness comparison is needed for practicing a useful workflow, but no comparative efficacy claim follows from use alone.

Later audit will recompute meaningful probabilities, identified-set and decision statements from artifacts rather than repeating asserted check flags. No new agents, provider API calls, package installs or GitHub writes are part of this review.
