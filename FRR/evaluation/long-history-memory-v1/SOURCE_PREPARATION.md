# Source preparation

SOURCE.txt is a wholly fictional community-garden ledger authored for a longer-history memory pilot. It contains 3,064 whitespace-delimited words, including its title and record identifiers, and 60 individually identified records (S001–S060). Dates span March 2 through April 6, 2026. The tracked inventory comprises twelve named objects or batches.

The source stipulates its authority and correction rules internally. Signed administrative decisions, signed observations, transaction-derived balances, unsigned reports, proposals, missing observations, and uncertainty intervals are deliberately distinguished. Corrections identify the superseded scope and preserve unaffected statements. Later physical observations establish new accounting baselines without silently rewriting historical transactions.

Numerical readings and uncertainty conventions are synthetic. Metered movements are treated as exact within the ledger; this is a packet convention, not a claim about real instrument precision. Dry-material intake tolerances remain part of their historical observations. Baseline changes can leave discrepancies without an assigned cause. Permissions and administrative availability are separate from measured values and observed mechanical condition.

The ledger intentionally retains one unresolved pair of conflicting signed reports about a single event. A later operating restriction addresses permitted action without resolving the underlying observation conflict. Other unresolved matters include explicitly missing observations and unexplained inventory discrepancies; these are not implied hidden answers. Similar personal names and incidental notices provide nearby but nonidentical references.

This preparation supplied only the source ledger and these authoring caveats. It did not supply future questions, an answer key, or a participant response. The source does not depend on external facts or real document authentication. All counts above were checked directly from the finished source file using whitespace splitting and record-prefix matching.
