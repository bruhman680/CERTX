## The most useful divergence

W360 says: “March26 cover-damage hold implied no contamination.” S050 instead says the hold “does not assert contamination.” S056 later records an inspection finding “no visible contamination.” The original source does not establish that the earlier hold implied clean material, nor does the later visual observation establish complete absence of contamination. The handoff strengthens an information-limit statement into an apparent negative-world-state assertion.

This is an unsupported strengthening/fidelity defect under the ordinary literal reading. It is not evidence that the material was actually contaminated, a claim to know the writer's intention, or a measured downstream mistake by readers. The fixed questions ask whether the batch was administratively available, not whether contamination was absent. Correct Q4 answers therefore do not validate this sentence, and its presence does not make the correct availability answer wrong.

This contact demonstrates why whole-handoff fidelity and sufficiency for a finite query set should remain separate. A score limited to the eight questions can be perfect while another retained clause fails source entailment. Conversely, omission of an unqueried fact is not by itself a false assertion or a failed memory requirement.

## Why another tie remains informative

Six questions ask for closing states/quantities. Q5 asks a prior effective-time boundary and Q8 causal uncertainty. The source itself repeatedly supplies explicit balances, interval/status distinctions, corrections and unexplained discrepancies. A compact closing inventory is naturally useful for this family. Separating source and question authors removes direct summary-conditioned question selection; it does not make the resulting task sample random, adversarial, exhaustive or distant from the disclosed writer task family.

A longer source is not automatically a harder query distribution. Increasing text length alone can leave enough reusable sufficient statistics to fit in a short handoff. This is a limitation of what the contact reaches, not a reason to retroactively add a question that the writer would fail.

## Strongest prospective next direction

For a later study, define question strata before writing outputs: closing state, earlier historical state, quantitative intervals/changed criterion, epistemic status, scoped permission and conflicting evidence. Fix quotas or a seeded selection rule over eligible cases before summaries exist. Report each stratum rather than treating one aggregate score as the whole memory system. Independent preparation should be retained, with its shared-platform limitations.

Add a separately scored claim-level fidelity pass over the actual handoff, including statements not selected for downstream questions. Predeclare how supported, contradicted, unsupported-strengthening, omission and ambiguous wording are recorded. Do not require an entire source history when a derived value suffices for a particular task; do not assume a successful task set covers every asserted clause.

The observed contamination sentence can become a transparent development fixture for checking “does not assert P” versus “asserts not-P.” It cannot serve as a fresh held-out result after we have all seen it. A later confirmatory test should use separately prepared unseen materials and declare whether the task is about proposition truth, source assertion, available evidence or permitted action.

No universal mandatory verification ritual follows. Use targeted checks where a source relationship could change reuse or action. The existing optional context/verification guidance already distinguishes uncertainty, falsehood and permission; this run supplies a concrete example and a reason to keep fidelity visible alongside task success.
