# First narrow full-weight fine-tuning pilot

30 October 2026. User authorized a bounded local training-readiness study and parallel arXiv scouting. One source scout supplied primary-paper design lessons; coordinator authored/reviewed the experiment. No independent experiment review. Three stages: freeze/build, train and evaluate, preserve/integrate.

Task: classify the explicitly recorded sampled-soil count as positive (YES), zero (NO), or unavailable (WITHHOLD). WITHHOLD is semantic source missingness, not epistemic abstention. No arithmetic, contradictory sources, approximate values or general confidence policy. `null`, `unavailable` and `not recorded` are explicitly declared missing markers. Other fields must not substitute for target.

Data:96training examples,12familiar-structure development examples,48structural-holdout test examples. Balanced classes in every split, generated by declared state oracle. Four training structures; four wholly held-out test structures. Every record includes unrelated zero and missing fields. Positive values also differ across splits. These are authored diagnostic examples, not natural-world observations or independently sampled evidence.

Primary: original vs final checkpoint exact normalized whole-label matches on the same48test cases using unchanged stored_run_audit.py, with full denominator, perclass/family confusion and constant-label baseline. Development is a familiar-format diagnostic, not checkpoint-selection data in this fixed pilot. One seed, one schedule, no retries, no test-driven changes. No aggregate generalization claim from a single split.

Full-model AdamW, CPU float32/eager,2threads,seed20261030,batch2,48optimizersteps (one96example shuffled pass),learningrate0.0001,weightdecay0.01,gradientnormclip1.0. Loss only over assistant target label plus EOS, normalized per example before batch averaging to limit unequal label-token-length weighting. No scheduler or hyperparameter sweep. Disable cache during training. Cap training at240seconds checked between completedsteps; if reached retain/report partial checkpoint. Also stop on nonfinite loss/gradients or loss of40% memory headroom when measurable. No substitute second attempt.

Single backward-only feasibility probe passed; it did not update weights. Training will save a separate full checkpoint and optimizerstate under /workspace/narrow_training_checkpoint_v1; original HuggingFace source remains unchanged. Evaluate baseline dev before training; final dev and both baseline/final test after training is complete. Greedy8token cap, freshcontextpercall, no gold labels in prompts. All source/model keys are hashchecked but gold labels are not parsed by the generation runner. Training labels are deliberately parsed from training data for supervised updates.

Keep raw outputs, training loss/timing, checkpoint hashes, optimizerstate, token/cache artifacts and all old histories. No paid resources, API, rental, package install or automaticdefaultpromotion. Research sources inform controls, not learning-rate guarantees. Acceptance is faithful execution and measurement, not a positive training result.
