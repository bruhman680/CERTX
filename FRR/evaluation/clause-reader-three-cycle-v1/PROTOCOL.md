# CR-C1/2/3: source-clause reader prerequisite

30 October 2026 UTC. Three prespecified bounded phases, 32 local greedy calls total, frozen together before any new inference. This is an exposed-fixture diagnostic follow-up to SR-C1, not three adaptive searches, a model-training run, or independent replications.

C1: Eight prior reading tasks, full source versus an explicitly selected verbatim sufficient span, 16 calls. Same instruction/question/model/64-token cap in each pair; source length and removed context intentionally differ. Count both semantic answers and strict formatting. Full arms intentionally repeat the earlier exposed inputs as a same-procedure check, not fresh independent evidence. Compare full-arm token sequences to SR-C1. There are no new arithmetic/conclusion queries.

C2: Reword only the question on the same eight selected spans, 8 calls, keeping instruction/model/cap unchanged. This tests sensitivity to one predeclared wording change, not broad robustness. Expected answers fixed. Do not search for a successful wording or select one post hoc.

C3: Eight newly authored short passages under the original C1 reading questions, 8 calls. New grouping counts 32,8,2,unrecorded; reset-status cases both nonzero provided, only qA supplied, both zero provided, both absent. Count source facts rather than infer any memory location. All cases/keys are author-authored before outcomes; these are not independently hidden population tests. Numbers/wording change together, so no isolated cause is claimed.

Each context starts fresh; no prior model cache is passed into a later prompt. CPU float32/eager, two threads, eval/inference, argmax, EOS stop,64-token cap. Preserve all raw outputs and new terminal caches. No retries, continuation, optimized prompts, paid APIs, training, default promotion or deletion of previous states. Stop/report any execution failure before considering a new run.

Selection is supplied by the coordinator, not learned/discovered by the small model. SELECTION.json binds each chosen span to parent source bytes and exact character offsets. Clause selection is justified for these reading questions only, not for previously asked numerical or identification questions. It removes information and does not preserve every task. Report input-token savings; token count does not measure selection cost or establish optimal compression. Coordinator selection time is not instrumented; report this as a measurement limit rather than free retrieval. No neutral-length or position-matched control is included, so a difference cannot isolate length, distractor removal, source position, or relevance selection.

Scoring is whole-response semantic match to separate frozen KEYS.json, with strict format separately. Sentence answers/case variants may match if unambiguous and without materially false added assertions. A copied numeral without an answer to the asked quantity is not credited; missing fields answered by a fabricated number fail. Source echoes truncated before an answer remain unresolved. A capped answer can still be right if already complete and uncontradicted, with cap recorded. Numeric absence must mean UNKNOWN, not zero. PROVIDED requires both numerical q values; zero is supplied, but one supplied q is insufficient. All manual semantic judgments are coordinator self-review, not independent/masked review.

Report paired outcomes by record, family and cycle; no population p-value or broad FRR advantage from this small deterministic exposed set. Source reading alone does not establish computation, joined reasoning, causal identification or autonomous selection. Preserve previous SR-C1 and all numerical findings unchanged. Warranted refinements may be appended after the run with their scope explicit.
