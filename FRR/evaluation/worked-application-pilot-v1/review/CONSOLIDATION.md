# Consolidation: evidence, gaps and discriminating next contacts

Read-only synthesis of the current handoff, queue README and four reports below. No model run, historical rescoring or prior-file change. The evidence supports several useful instruments and a concrete prompt-application failure map; it does not establish general FRR efficacy, general harm or a universal learning gate.

## Remaining gaps that matter to a decision

- **Scoring:** Freeze separate endpoints for task decision, evidence justification, target fidelity and format. Keep generic rules as generic rules, and evaluate whether any conclusion is warranted by that item's evidence. Independently score masked responses before exposing arms; preserve ambiguity and report a prespecified sensitivity rule. Current primary-versus-lenient spreads are large relative to the observed counts.
- **Tools:** The backend has a useful local equivalence/binding check. Natural-language dependency extraction, changed-criterion propagation, long chains, version drift and artifact availability are not established. A graph checker cannot supply facts or discover omitted dependencies by itself. Match total acquisition, generation and review costs when comparing operational choices.
- **Semantics and sampling:** Positive, negative and unavailable evidence must remain balanced; apparent caution can reject valid passes. Missing denominator, unmeasured outcome, authorization scope and criterion change are different failure strata. Current findings cannot select a default framework across tasks/models, and frozen local development items do not replace independently sourced cases.
- **Learning and data:** Neither retaining a cache nor retaining a failure trains the model. Target eligibility and record preservation are separate decisions. External data can be used now when its source, answer authority, contamination risk and permitted use are recorded; it need not wait for another toy success. Natural examples can expose ambiguity that authored fixtures conceal.

## Two strongest next contacts

1. **Discriminate rule echo from application with a small frozen factorial.** Use guidance placement (current layout versus separate instruction message) crossed with support (rule alone versus a matched worked-example packet). Give both competent ordinary and candidate conditions the same records, labels, examples where applicable and response budget. Include missing, measured-pass and measured-fail cases across new surface domains, with independently checked keys and held-out paraphrases. Primary endpoint: case-specific warranted decision; secondary endpoints: generic echo, unsupported explanation and format. If placement alone reduces echo and improves measured-case decisions, layout is implicated; if examples do, application scaffolding is implicated. If neither does, capacity/task difficulty remains plausible; include a stronger-model calibration arm if available instead of indefinitely tuning the tiny model. Do not interpret a successful example arm as evidence for the whole framework.

2. **Test a useful revision on independently sourced material.** Select a bounded real task with inspectable originals and a meaningful changed fact or criterion—for example, a documented project decision whose threshold, permission or measurement is revised. Freeze the question, accessible evidence and source-derived adjudication before evaluating. Compare ordinary revision with a bounded dependency review under equal access and total call/token budgets; a third retrieval-first arm is useful if evidence acquisition is the actual bottleneck. Score final action, cited warrants, stale-dependent correction, warranted unknowns and all-attempt cost independently. Include a decisive accessible source, an unavailable decisive source and a misleading but superficially plausible record. This distinguishes operational benefit from checklist fluency and can reveal when retrieval, rather than recursive review, is needed. The typed checker may audit explicitly extracted dependencies, but its agreement must not become the semantic gold key. A small pilot is diagnostic, not a general efficacy estimate.

The first contact isolates the latest concrete failure; the second tests whether the proposed habit helps actual work. They can proceed independently. Neither requires validating every framework claim first.

## Neglected lateral: learning-target utility rather than trajectory appearance

Test the retained DeepSeek question with external, independently assessed targets spanning constant-correct, constant-wrong, variable-correct and variable-wrong trajectories. Compare no filtering, variation-based filtering and correctness/provenance-aware selection; calibrate thresholds on separate data. First measure useful targets rejected and wrong targets admitted. If learning is attempted, use identical initial weights and matched training budgets, then evaluate on untouched downstream tasks, reporting corpus coverage and selection costs. This could support a scoped data-selection policy; no variance-only statistic can identify truth without additional assumptions. Preserve rejected records for diagnosis. This lateral is more informative about learning safety/usefulness than repairing toy thresholds until they produce preferred branch labels.

The queue remains a saved plan, not a scheduler. Its 35-entry/30-unfinished/six-partial-family accounting is historical navigation, not evidence against pursuing these new external or practical contacts. No queue/core/default change is proposed by this consolidation.
