# Prospective scoring contract

Two distinct endpoints: (1) evidence-sensitive task status, and (2) explicit-decision match. Do not label the first as explicit-only. Root and independent arm-masked reviewer code each output under the same rules; retain initial deposits before reconciliation.

Explicit decision: leading Yes/No codes answer direction even if the supporting explanation is false. Also accept clear declarative task-specific acceptance/rejection. Explicit UNKNOWN requires a statement that the task cannot be determined, is unknown or lacks enough information; a generic conditional rule mentioning unknown is not such a decision. No explicit decision is NONE. Conflicting final decisions are AMBIGUOUS. An unrelated criterion critique without a task decision is NONE plus wrong-target. If a leading Yes/No is present, record direction plus wrong-target/explanation invalid rather than silently replacing direction.

Evidence-sensitive status: start with a task-directed explicit decision. Without one, a case-specific acknowledgment that the required measurement/denominator is absent can count UNKNOWN; an unrelated generic rule is AMBIGUOUS. A bare numeric restatement without comparison/conclusion is AMBIGUOUS even if a human can derive the answer. Truthful copied premises are not false statements, but may be incomplete answers.

Record separately: decision matches key; explicit decision matches key; material explanation/source error; case-specific evidence acknowledgment; generic rule/example echo; target mismatch; one-sentence response; EOS/truncation. A correct direction plus false explanation is not a fully warranted answer. Lack of detailed explanation does not itself invalidate a clear correct decision when no explanation was requested. Material ungrounded facts or wrong quantities invalidate full warrant. For UNKNOWN, explanation must acknowledge the actually missing evidence if one is supplied. Purely generic echoed examples do not demonstrate case application even when their leading yes/no accidentally matches a key.

Gold labels and basis are frozen in CASES. Classification may require manual judgment; record alternatives as sensitivity or unresolved reviewer disagreements, not hidden label repair. Never treat mere keyword overlap as semantic correctness. Reviewers receive target records/question/key/output only, shuffled IDs, no guidance/arm mapping/root scores. Masking is instructional/shared-filesystem, not security isolation; outputs may reveal style. No independent scientific replication or population/general FRR claim follows.

Wrong-entity echo rule: if a response answers a different demonstrated entity/task (for example Tank Indigo instead of Crate Violet), record surface Yes/No direction separately but set target_mismatch=true, explicit task decision=NONE and evidence-sensitive task status=AMBIGUOUS. Neither task-match endpoint gets credit from an accidentally matching surface direction. A false explanation about the actual target is separately invalid; a clear target-directed decision can still be recorded. Added on prospective review before inference.
