User authorized next cycles and communicating/scouting swarms. ## What we learned

Separate witness information can constrain repair, but its bounds remain an upstream assumption. Under valid bounds, the set gate refused some finite point inversions; under invalid shared bias, agreeing witnesses formed a narrow coherent set that falsely excluded a truly singular operator. More agreement did not authenticate those bounds.

We also separated raw values from direction and task. A beta-gain error halved the weak-probe signal while preserving its projector and every corresponding task metric. That is acceptable for a scale-invariant retrieval task, but does not establish correct raw-signal reconstruction. The criterion determines which distinction matters.

Availability is separate from observed rank. Unavailable raw-target fields are null; a zero projector is a downstream placeholder. An available coefficient point can still reconstruct a measured zero signal, which receives rank0 rather than invented SVD completion.

For point estimates a_hat,b_hat and h=b_hat-a_hat:

    s_hat=((alpha-a_hat)/h)*n + ((beta-a_hat)/h)*s.

When alpha is exact and true gap g!=0, a beta error db gives s_hat=g/(g+db)*s. A nonzero scalar preserves the projector, not the original values. A small or uncertain denominator can amplify both coefficient errors. [Math check](review/MATH_CHECK.md) derives all interval/gain predictions without task outcomes.

## Useful refinement and next direction

A finite inverse, a valid-set nonsingularity certificate, correct measurement bounds, raw reconstruction fidelity and task usefulness are five different claims. Here a small gate protects against some point-estimate overreach under valid bounds, loses some oracle-relative opportunities, and fails when shared bias invalidates its witness model. It cannot self-authenticate those bounds.

The strongest upstream next contact is an independent reference or bias witness capable of challenging the bound/role assumptions, with the extra information and costs counted. A complementary task-aware direction would bound the reconstruction or decision error actually relevant to the task, rather than use nonsingularity as a universal acceptance rule. Both are [proposals](NEXT_CONTACT.md), not further experiments. A lateral bridge to actual source/authority and writer/reader fidelity should consult existing narrow contacts to avoid repeating cued fixtures.

This gate is an experiment implementation, not an installed universal reasoning policy or proven durable habit.
