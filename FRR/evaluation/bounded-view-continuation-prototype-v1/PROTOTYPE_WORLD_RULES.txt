# Computational notebook world: environmental laws

This detached candidate inherits the exact supported filesystem at immediate parent entry 1580, with original reference1550 preserved in its ancestry. The archive files and this declared body/view description are explicit operator additions in the clone. The existing pretrained weights and environmental execution laws remain unchanged.

1. A reply is writing. Its exact text is retained externally and an append to `/world/notebook.txt` is attempted. A known write error is returned as a real consequence; it does not prevent independent lawful code cells from running.
2. A complete cell opened by a column-zero line exactly ```python or ```sh and closed by a column-zero line exactly ``` executes its source, unchanged. Python uses `python3 -I -S`; sh uses `/bin/sh`. Cells execute once in textual order. Other text is inert writing. Unknown-label, attributed, unlabeled or longer backtick fences shield their contents and do not execute. Incomplete cells do not execute. No source is dedented, repaired or extracted by semantic judgment.
3. Supported files, modes and links in `/world` persist. Each cell starts a new process: Python variables, shell variables, processes and `/tmp` do not persist between cells. A program can store code, data or notes in files and read them later. Actual stdout, stderr, exit status and resource boundaries return after each reply. An ordinary error does not erase state or suppress later cells.

The world does not require an action, achievement, useful result, correct thought, improvement, specific reasoning method, or a particular developmental phase. Statements about operations do not perform those operations unless they are part of a declared executable cell.

## Finite physical limits

- Eight complete executable cells per reply. Over-limit replies receive a boundary receipt before guest operations; raw text remains externally retained.
- Per cell: 3 seconds wall time, 2 CPU seconds, 32 MiB address space, 64 open descriptors, 256 KiB per file, 8192 captured output bytes. The user process count is bounded at 128.
- Writable world data: 8 MiB. Temporary data: 8 MiB. These are data quotas, not a complete accounting of kernel metadata or every host allocation.
- The read-only software runtime supplies ordinary shell and Python semantics. Host research files and network are unavailable. This is a broad established interpreter/runtime behind a small interface; it is not a claim that all Python/OS behavior has a Conway-sized specification.
- Unsupported checkpoint states, uncertain effects or dependency drift cause an explicit pause with retained evidence. They are never silently repaired or automatically replayed.
