# Room for error downstream

Prospective local inference contact, designed after the prior acquisition/bridge/frame results and the user's request to allow uncertain failures farther downstream. Freeze data, scheduled calls, prompt templates, scorer, instruments and checkpoint hashes before any new model forward. No training, output-dependent retry or early accuracy gate.

Use the fixed final canonical YES/NO/WITHHOLD adapter from simple-readout-acquisition-v1. It is selected in advance because it acquired the simple readout and its prior two-record answers are all valid labels; this contact concerns semantic failures, not all prior alias/invalid-output behavior. Same saved weights in fresh reader contexts are not independent agents or learning. One bounded downstream pass is not recursive improvement, error-awareness, or general FRR efficacy.

Cycle A: replay all36prior two-record sources and their actual canonical proposals, including23correct/13wrong. Do not screen errors out. Six conditions: no-proposal full source, no-proposal selected crop, deliberate other-record crop, proposal-only/no-source, proposal+reopened full source, proposal+selected crop. These are exposed regression sources; outcomes cannot be represented as fresh primary evidence. A fresh no-proposal full reading should reproduce prior exact outputs under identical tokenization; disclose any mismatch. Direct pass-through23/36is a mechanical reference requiring zero new model calls.

Cycle B:12fresh study sources using Spruce/Fir,3target states,both target identities,both target positions. Distractor is the next state in a fixed cyclic order, hence always conflicting; this is a restricted design, not all distractor assignments. For each source run the three no-proposal source conditions above. Then pair each source with correct,wrong1,andwrong2proposals, balanced across the same three labels, and run proposal-only/full/selected conditions for each seed.144fresh calls plus216replay calls=360generated answers, plus360three-choice scoring batches (1080candidate sequences). Previous results inform design; all these inputs/metrics freeze before their forwards. Repeated prompts are counted, not treated as independent evidence.

The model gets only prompt text derived from proposal and permitted evidence; authored gold/IDs never enter prompts. Each reader starts with fresh cache. Greedy8tokens/EOS, same explicit three-choice sum-logprob and mean diagnostic. Invalid remains in denominator. Record wrong→correct, wrong retained, wrong→otherwrong, wrong→invalid, correct retained and correct→wrong/invalid. A changed output is not proof the model recognized an error, and a lucky correct output without evidence is not grounded. No model confidence or calibrated rejection inferred from these classes. WITHHOLD remains the semantic label for an explicitly supplied missing status, not an epistemic uncertainty action.

Cycle C: after all scheduled movement, a narrow source receipt checks source availability/bytes, selected target identity/content, and output consistency with the declared source grammar. It reports UNSUPPORTED/TARGET_MISMATCH/etc separately from label correctness. It does not block an experiment or rewrite answers. Correct selected crops come from an explicit source parser; improvement with them is tool-supported, not model-only recovery. Wrong selections are deliberately allowed through to expose plausible error propagation. Source grammar is the toy reference, not external-world truth or an independent empirical evaluator. Independent source repair/versioning remains outside this contact.

Record prompt/token/output/choice scores and elapsed/token costs separately from total compute. Sampled working-estimate guard5153960755bytes; two CPU threads/eager float32, original pinned base. No model downloads, packages, paid API or rental. Full KV tensors are not saved. Preserve old source/weights/results; no core/default model or verifier promotion. Authored fixtures and coordinator audit are not independent replication. A guard/ordinary failure leaves partial records; no automatic retry or cleanup deletion.
