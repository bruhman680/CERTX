# Carried garden exploration — first bounded season

2 November2026 client date. User explicitly reframed improvement as development of public responses to persistent failure/uncertainty, including errors, not only accuracy. This is an exploratory trajectory study. No successful emergence, plateau, self-correction or new strategy is required per run. No training/weight update.

Two10-round episodes x two stochastic seeds x full-history/short-history =80generation calls, each <=64new tokens and <=2048input tokens, CPU float32/eager2threads, same canonical135M adapter. Model maximum positional limit is8192; the experiment uses a lower resource ceiling. No candidate projection or probability scoring. Temperature.8, top-p.9; matched seed per episode/round across history conditions, with fresh KV cache per call. Matched sampling reduces one source of variation but does not create independent replications. Parameters and prompts are not tuned after seeing outputs.

Active full-history trajectory retains every earlier observation, raw reply and actual verifier feedback from its own episode/seed. Short-history is a matched replay control receiving exactly the latest active event, current observation and same instructions; its replies are recorded/scored but do not drive the active trajectory. It is not an independently evolving second agent. At round0prompts and RNGseed match and should produce identical tokens. Future rounds can diverge due to older history; different context length is intrinsic to this comparison, not separately isolated.

Public outputs can answer, ask, note uncertainty or propose a different approach; no mandatory explanation or strategy schema. Only a recognized first-line label is task-scored. A question/note without that label is UNSCORED, not counted as a failed reasoning event. Recognized labels receive matched/nonmatched feedback without the correct label. Evaluator expected labels stay outside prompts except the task's general mapping. No generated question is automatically executed as a tool call. Replies do not alter code, weights or the fixed environment schedule.

Episode1 repeats a challenging zero record, changes only its layout at round4, then presents literal missing on a new plot at round8. Episode2 starts with genuinely absent records, supplies a positive record at rounds4–5, then removes it. These are externally scheduled interventions and must never be reported as emergent model phases. Keep the original task contract fixed. Notebook persists explicitly as append-only text and JSON files; sampled replies are carried verbatim without pruning or replacement. If the2048token resource boundary is reached, stop and record that boundary rather than silently truncate. All raw notebook history remains saved even if a boundary prevents continuation.

Measure event sequences, recognized/unscored outputs, repairs/harms only across repeated identical observations, response/token recurrence, output lengths/stops, earlier-history versus matched-short-history differences, and predeclared schedule boundaries. Label streaks or textual repetition are descriptive, not proof of understanding/crystallization. Optional human inspection records quotations separately from interpretations; candidate noticings are hypotheses needing later fresh tests. No stopping after a favorable outcome; complete all10rounds or record a resource stop. No claim that a finite quiet tail is an intrinsic plateau.

Save source/protocol/schedule/runtime/checkpoint hashes before loading. Save exact dynamic prompts, token IDs, RNGseeds, history references, raw replies, feedback and every notebook version. Verify history reconstruction, no evaluator-answer leakage through formatting, first-round paired equality, scores, hashes, resource limits and unchanged weights. Preserve every failure/uneventful run. At the end checkpoint all four active notebooks for continuation; do not automatically start another batch or train on these outputs.
