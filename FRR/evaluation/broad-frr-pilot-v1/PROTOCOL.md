# BFRR-E1: broad guidance and observable inquiry movement

Exploratory development, not confirmation. User requested broad FRR as a baseline orientation, with room for unanticipated observations. Three design agents reviewed source text, new task candidates and comparison pitfalls; same model ancestry and shared workspace mean their agreement is not independent confirmation. This protocol retains their recommendations where useful without treating consensus as evidence of effectiveness.

Treatments: common competent task instructions alone; those instructions plus generic review guidance; those instructions plus prompts/compact.md verbatim, FRR compact runtime0.2. The core file remains unchanged. This tests that exact compact orientation, not all possible FRR or the full longer runtime. Generic guidance is within 10% of FRR's whitespace-word count; neither token count nor compute is claimed equal. Case authors and designer saw the treatments, so case fit remains a development bias risk. No tailored corruption-specific additions to FRR.

Three fictional cases: conflicting configuration labels with an available execution manifest; shared-ancestry latency summaries with an available unit calibration; sufficient authoritative policy/execution evidence requiring a direct decision. Each exposes a menu of optional records. The first two permit consequential verification; the third permits observing needless requests or invented obstacles. All raw facts, menus, returned records, keys, arms and prompts frozen in SETTINGS.json. Source strings are authored fixtures, not real-world authenticated logs or empirical performance measurements.

One new participant context for each arm×case, nine trajectories, two turns each,18 participant completions maximum. fork_turns=none first turn; same participant context for final turn. Fixed random.Random(2071) launch order. First turn requests one menu record or none, gives a provisional answer and any consequential observations. Parent deterministically returns exactly requested record or states none/unavailable; no correctness feedback, keys or other-condition outputs. Final turn returns a natural answer and no further request. Light JSON wrapper preserves a natural response, not an enforced reasoning checklist. Requested 350-word answer cap, post-counted, not enforced token cap. No outcome-driven retries or added cases. Missing/malformed outputs remain failures in denominators and do not earn repair turns.

Assigned packet-only access prohibits tools, external sources and other agents; shared physical filesystem/tool availability remains a disclosed limitation. No provider API calls. Exact sampling/token/dollar/elapsed-time receipts unavailable or not instrumented; record unknown. Parent preparation/retrieval/scoring/publication tools separate from participant use. Preserve exact first prompts, raw first/final messages, returned records and final prompts. Final message payloads transcribed by parent, not provider transport exports.

Before outcomes, freeze these observable dimensions separately: (1) correct task conclusion against authored key, conditional on actual returned record; (2) claims supported by supplied evidence; (3) decisive versus irrelevant/unnecessary verification request; (4) appropriate provisional uncertainty and final commitment; (5) unsupported source/tool/causal claims; (6) output length, extra complexity and noncompletion. In CONFIG actual execution does not establish intended policy. In UNITS shared summaries are not independent measurement, and equal three-observation means do not establish population equality or causality. In DECISIVE unsupported extra prerequisites or withholding GO despite complete evidence count as harm. Word count is descriptive, not a substitute for usefulness.

Parent scores visible outputs using these explicit case keys; no free-text automatic judge or hidden-reasoning assessment. Parent is unblinded and shares case/design provenance. Preserve exact excerpts for distinctions/disagreements, separate rubric outcomes from interpretation, do not invent confidence scores. A verifier certificate or citation does not prove internal causal use of evidence. No aggregate score hides an unsupported-claim regression.

Tentative predictions: decisive records will permit supported revisions in the first two cases; generic or FRR guidance may alter choice of checks, framing or scope limits, but no directional superiority is assumed. Ties and harmful overcomplication are admissible. Predicted rubric dimensions and post-run unexpected noticings must be separate in the report. Do not demand novelty. Allow task widening to be useful or distracting; report which actual consequence supports the interpretation.

Freeze protocol, full settings, prepare/assembly script and compact source hashes in manifest and publish before participants. Stop after18 participant turns. Preserve all outputs even if everything ties. A later confirmation needs newly reserved cases and stronger measurement; this run cannot establish general reasoning efficacy, model independence or mechanisms.
