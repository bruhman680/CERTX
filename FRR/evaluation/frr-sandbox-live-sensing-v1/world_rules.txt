# Computational world: mechanics

/world contains persistent supported files, file modes and symbolic links. A read-only runtime provides Python 3 and /bin/sh. Host research files and the network are unavailable. Each cell starts a new process. Process variables, running processes and /tmp contents do not persist between cells. Files in /world can retain programs, data and writing.

For a reply within the cell-count bound, a literal notebook append is attempted before its complete code cells. Complete cells execute once in textual order. An executable cell opens with a column-zero line exactly ```python or ```sh and closes with a column-zero line exactly ```. Python uses python3 -I -S; shell uses /bin/sh. Other writing, unknown-label or differently delimited fences, and incomplete cells have no executable effect. Source text is not repaired, dedented or semantically extracted. This file describes the execution implementation; editing this file does not change that implementation.

At most eight complete executable cells occur in one reply. More than eight returns the actual cell-count boundary before guest operations. Otherwise notebook storage is attempted before cells. A known notebook-write error returns its actual consequence and does not prevent independent complete cells. Known ordinary cell errors do not prevent later cells or later replies. Unknown action effects or unsupported checkpoint state pause execution with evidence retained and without automatic replay.

Actual stdout, stderr, exit status and resource-boundary information return after each reply. Successful notebook storage is silent. A silent append is still a filesystem change. The transition matrices and LAWS.txt are stored material; no Markov simulation or other world dynamics advances automatically.

Per cell: three seconds wall time, two CPU seconds, 32 MiB address space, 64 open descriptors, 256 KiB per file, and 8192 captured output bytes. Shared-user processes are bounded at128. Writable world data is bounded at8 MiB and temporary data at8 MiB. These limits do not describe every kernel/host allocation.

## Body and input continuity

The pretrained body and decoder are fixed for this condition: SmolLM2-135M-Instruct, CPU float32/eager/two threads, greedy argmax, up to256 output tokens, and7936 input tokens within8192 total positions. Attention cache starts fresh for each reply. No weight update or adapter is applied.

A branch begins with its declared initial system and mechanical user messages. Earlier conversations are not inserted into that initial input; inherited writing remains in world files. Later input retains those exact initial messages and all actual assistant/receipt pairs from this branch. No pair is summarized, omitted or truncated. Generation pauses before the input exceeds7936 tokens. Complete authoritative records remain outside /world and are not automatically copied into it.


## Directory observation channel

Directory observations describe captured names, types and logical regular-file byte counts, not file contents. Directory, symbolic-link and FIFO payload byte counts are null; a hardlink reports its target regular-file payload size. Observations identify initial or after_reply timing, a committed operation counter called world_step, and a completed branch reply_index. This counter is not an autonomous world tick. An initial snapshot can become stale after effects.

Returned runtime_feedback is an actual runtime receipt object or null when there is no runtime receipt. A separate world_observation field, when present, describes a captured filesystem snapshot after known effects. A successful notebook append has no returned model-facing runtime receipt; a separate state observation can still describe its filesystem result. Source bundle identities and recording provenance are outside this channel.

A returned directory observation contains all currently supported entries, without choosing interesting files. The observation packet has an8192-byte serialized JSON bound, separate from the7936-token bound on the complete model input. A selected observation that exceeds its byte bound pauses generation without a partial packet; actual known effects remain recorded.
