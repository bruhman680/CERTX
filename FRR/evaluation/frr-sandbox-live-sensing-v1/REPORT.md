## A useful lateral witness: complete metadata is not full state

The read-only probe under aliasing/ reuses two previously completed, verified program-transfer worlds. Their43 names/types/sizes produce the exact same3393-byte sensor text under matching timing/counters. The current file probe_value.json is19 bytes in both, but contains different values. The same previously executed reading artifact returned different stdout in those worlds.

This proves a narrow and useful limit: the metadata projection alone cannot determine all file-dependent action consequences. It does not prove the sensor useless or that the model cannot actively acquire the missing content. A real read and its actual receipt can distinguish the worlds; the claim is not that the full future input would stay identical after such a read. Source chains, CAS contents and the old actual consequence records are linked without any new model call, world action or sandbox open.

This connects to the earlier hidden-present-state versus memory distinction. An unexplained difference need not originate in the model's memory or reasoning; a present variable may simply be absent from the observation. The witness is an instance of partial observation in our actual tooling, not a new general theorem or a test of neural mechanisms.
