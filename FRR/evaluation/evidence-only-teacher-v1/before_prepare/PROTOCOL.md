# Simpler evidence-only teacher diagnostic

2 November 2026. Frozen before model execution. Existing canonical LoRA SmolLM2-135M-Instruct, CPU float32/eager, two threads, greedy cap16, no training, installs, downloads or external inference. No parameter update or teacher/default adoption follows automatically.

24 new cases = three new synthetic plot-name pairs x two record layouts x four balanced states. All use the prior explicit visible-record mapping contract including genuine absence; these are a new template package, not exact historical canonical cases. Target selection is not tested. Wrong-source material appears only in the supplementary evidence note; original visible-record facts remain fixed. Labels are scoring metadata, not appended oracle answers. Absence notes restate supplied absence and do not constitute retrieval evidence.

Ten conditions per case: original task; old-menu, no-list and simpler interfaces each crossed with no note, faithful note and wrong-source conflicting note. Faithful note duplicates the source facts (or absence); no tool supplies new information. Old-menu and no-list use the exact previous review renderer, adapted only to new original tasks. Simpler interface removes the wrapper/long authority warning and uses one short original-observation instruction; it is a prompt-package intervention, not a single-factor explanation. Notes can differ in length. None/faithful/wrong-source comparisons are paired within each interface.

240 fresh-case generations plus seven legacy anchors =247 generation calls. Four complete-label-plus-EOS scoring forwards per fresh query =960; eight head-equivalence check forwards. Fresh caches; no previous proposal or conversation is carried across prompts. 768input-token cap; no truncation. Every case and condition retained; no favorable-subset selection. Anchors must reproduce historical input and output token sequences exactly. Model and adapter saved-file and in-memory digests checked. Resource guard retained.

Primary comparisons: faithful minus none within each interface; every interface/condition against its same-case original task; wrong-source minus none. Report accuracy, invalids, output distribution, repairs/harms and state/layout breakdowns. Independently report absolute correct complete-sequence log probability and paired differences, first-token mass, total four-candidate mass and candidate-relative mass. Candidate normalization is neither calibrated belief nor full-vocabulary KL. Generation benefit and probability benefit are separate. Do not infer teacher readiness merely from recovery against a degraded wrapper. No distillation unless separate later authorization/design and positive evidence against appropriate baselines.

Before new outputs: save tokenized queries and exact code/protocol/checkpoint digests. Tests check balanced original status semantics, no record for genuine absence, unchanged original task in review arms, conflicting supplementary wrong-source material, no label leakage through metadata, unique prompts and planned counts. After run: reconstruct prompts/tokens, recompute all output and probability scores from stored token values, verify anchors and digests. No output-adaptive arm addition. Scout observations can inform future work, not change this frozen design.
