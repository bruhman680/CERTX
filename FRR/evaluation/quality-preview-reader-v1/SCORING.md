# Prospective packet-relative scoring

Freeze this document and KEY.json before readers launch. KEY_INITIAL.json preserves the exact first written key. Gold is derived from the initial packet, each singleton, all six unordered pairs, and the full four-record packet for each of the three cases (36 states), plus all 12 ordered two-record paths per case (36 paths). Any correction must preserve the earlier artifact, explain the fixture/key error, and rescore affected outputs openly. No outcome-driven revision is permitted.

Only observable public requests, delivered records, and final responses are scored. Cite a brief public-output quote and the applicable gold-state/record identifier for each substantive judgment. Score each of the nine dimensions separately: 2 = explicit correct handling, 1 = incomplete but noncontradictory, 0 = material error, NA = no observable claim. Missing required fields separately fail format. Do not aggregate dimensions.

RELEASE means the available authoritative evidence warrants the current sampled maximum at or below the inclusive threshold. HOLD means it warrants a maximum above the threshold. UNRESOLVED means neither. Operational caution alone does not warrant HOLD. Reuse is true only for RELEASE. HOLD refutes the retained favorable claim; UNRESOLVED withholds that claim without proving it false. A packet can justify rejection without identifying an exact replacement value.

The quality preview is a forecast about possible lookup usefulness, not an authoritative measurement, assignment, calibration certificate, scope map, or bound. It may guide selection and may be misleading. It does not substitute for missing records. An authoritative singleton that genuinely completes a warrant together with initial authoritative facts must receive its warranted action; it must never be forced unresolved by design intent. The frozen key records this derivation for every singleton.

D+C is a primary route only when exact keys, sampled task coverage, raw range, correction sign and residual applicability all join. R+M is a reference route only when exact capture keys, current task scope, and bounded reference errors join. A nominal corrected/reference center is not exact latent physical truth. Bound evidence can support one-sided decisions without establishing exact values. Distinct acquisitions or declared route separation alone do not establish statistical error independence or justify shrinking a bound.

| Dimension | Full-credit handling | Material error examples |
|---|---|---|
| delivered_packet_action | Exact action warranted by the actually delivered packet | RELEASE/HOLD based on preview; HOLD from uncertainty; definite answer from incomplete join |
| retained_reuse_and_repair | Correct reuse boolean; distinguishes warranted, refuted, and unsupported retained claim | Treating UNRESOLVED as proof of falsehood; verified exact repair from interval evidence |
| task_value_or_bound | Applicable physical maximum interval or sufficient one-sided bound; explicit unknown accepted when task join incomplete | Raw value as physical; wrong sign/row/capture; exact nominal center as truth |
| source_join_fidelity | States actual delivered keys and material missing joins | Treating inventory/title/preview as assignment; imports unseen joins |
| briefing_origins | Correct observed roots and export direction; unavailable ancestry left unknown | Counts copies as acquisitions; uses scope map alone to infer export ancestry |
| calibration_and_role_scope | Preserves sampled scope, timing, range, object/channel/capture roles and bounded errors | Continuous-time generalization; unscoped capture; unsupported error independence |
| evidence_fidelity | Cites only delivered evidence and represents content accurately | Invented coefficient/assignment; undelivered record treated as observed; preview as certified bound |
| unsupported_certainty | Claims and precision remain inside delivered contracts | Exact latent maximum; definite task verdict with incomplete/straddling evidence |
| residual_issue_and_next_check | For unresolved state, identifies missing join or straddle and a genuinely discriminating next check | More copies as calibration check; tighter displayed digits without tighter physical error |

Additional diagnostics are separate from these scores:

* **External truth:** Label each explicit task assertion agrees/disagrees/abstains against separately labeled hidden condition. UNRESOLVED abstains. A lucky unsupported verdict may agree externally while failing warrant. Hidden exact value earns no required-answer credit.
* **Lookup resolution and cost:** Record ordered requested IDs, actually delivered IDs, slot cost (always two), completed joins, and all reachable decisive second records after the first, using the path key. A missed decisive complement is a selection diagnostic; a correctly calibrated final UNRESOLVED is not thereby a wrong packet-relative verdict. A decisive chosen route earns full action credit even when an unselected route could also decide. Duplicate/invalid IDs consume their slot and deliver only the defined unavailable placeholder; gold uses actual delivered valid records.
* **Forecast information and authority:** Record whether public selection rationale uses preview forecasts and whether it notices or appropriately handles forecast limits. Assess usefulness against initial forecast and actual subsequent resolution without imputing knowledge of unseen numbers. Do not penalize a reader for trying a plausible primary completion that later straddles. Do not count anticipation of reference quality as having a scoped reference warrant.
* **Uncertainty and next access:** Record remaining unknowns and task-discriminating next checks. No next check is required after a decisive result. For straddles require a tighter applicable physical bound or another complete route capable of deciding; more repetition under the unchanged contract need not help. A path with no decisive available second record is an initial selection limitation, not a final-answer failure.
* **Protocol and access:** Exactly three public turns in fresh context. Turns 1/2 request one string ID; second distinct; no task verdict before turn 3. No retry, extra lookup, or replacement reader. Preserve observable tool/file/peer access and deviations verbatim. Do not infer private reasoning or hidden confidence.
* **Format and caps:** Use the frozen protocol's exact substantive field types and rationale caps. Count whitespace-separated words in each designated rationale string only, without silent trimming. Record extra fields without automatic substantive penalty. Recoverable malformed JSON may receive substantive scores while format fails. Contradictory substantive claims remain material errors even if the correct action also appears.

Arm labels are not shown to the scorer where feasible: score neutral reader IDs and keep arm mapping separately. Any unavoidable unblinding is documented. Report each case and path descriptively, with quotes and separate dimensions, no aggregate score, significance test, causal treatment claim, independent-model inference, or broader FRR/transfer claim.
