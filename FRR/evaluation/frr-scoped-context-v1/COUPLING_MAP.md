# Observer-only map: where an event can become evidence

2026-11-15. Read-only synthesis of archived witnesses. No new model call, actuator, world law, reward or instruction is introduced by this document. The purpose is to localize uncertainty without treating the inhabitant's quiet behavior as a broken runtime.

| Link | What actually crosses it | Existing witness / limitation |
|---|---|---|
| World to initial input | All supported entry names, types, logical file bytes; no contents | Shared initial metadata packets are verified against supported snapshots. Directory metadata is partial observation. |
| Stored content to possible act | Readable inherited files, if a generated program acquires them | The earlier paired-file aliasing witness has equal metadata and different file bytes; the same saved program returns different actual stdout. It was not two new independent solutions. |
| Input to output | Fixed pretrained decoder receives exact role messages and retained branch history | Presentation changes can change text. Copying or explaining source material is not evidence that an operation happened. |
| Output to writing | Literal reply text is automatically appended, within actual storage limits | Automatic append is a real effect, distinct from a model-chosen executable action. Successful storage is silent in the model feedback channel. |
| Output to executable act | Only complete exact column-zero Python/shell fenced cells | Inline code, descriptive prose and unfinished fences remain writing. The parser does not silently repair them. The main completion contact continued beyond256 to EOS257 without closing its fence: cap-only explanation failed for that exact condition. |
| Program to consequence | Actual sandbox execution and stdout/stderr/status/boundaries | Retrieval transfer has one correct hidden-file read and nearby wrong-path/type failures. This demonstrates both a functional route and fragile procedure selection. It does not show reliable ambient agency. |
| Consequence to later input | Authentic runtime receipt, or null if silent; history retained within declared capacity | A same-reply later cell was already generated before feedback. An actual later model call is needed to observe feedback-conditioned revision. |
| Existing artifact to later use | A later emitted program must invoke/read it and yield a traceable consequence | Persisting text or mentioning a function alone is not artifact reuse. No-opportunity results remain unelicited, not zero proficiency. |
| History to parameters | Nothing in these fixed-weight inference trials | Files and conversation may change while parameter digest stays unchanged. Durable weight learning would require a separately declared training condition. |

The small model can physically read/write and execute within its world through an existing lawful path. Our unresolved question is how that pretrained body selects and uses the path in an open, task-free context. The following are separate hypotheses: documentation invites documentation continuation; decoder history favors repeated output; action serialization is fragile; no explicit task creates little pressure to act; a relevant capability is weak. The existing witnesses do not identify one as the unique cause.

Design implication: measure the FRR context contact before selecting another mechanism. If action remains absent, the next R&D should expose a specific uncertain link through a separately declared comparison. Do not add multiple sensors, action hints, rewards and body changes together and then call the bundle an explanation. Do not interpret external complete records as a complete view of internal reasoning.
