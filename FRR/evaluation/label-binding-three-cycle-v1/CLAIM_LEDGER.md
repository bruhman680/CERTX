# External claim ledger: a label is not its claimed referent

Observer-only refinement. This ledger is not inserted into any model input, not a behavioral gate, and not a correction to the main world. Literal labels can be extracted automatically; interpreting an assertion and checking its support remain explicit, scoped observer steps.

| Supplied item | Actual supplied type/value | Generated assertion | External support check |
|---|---|---|---|
| world_snapshot | Key containing a directory metadata object | File containing responses to questions | Source snapshots list five other actual paths, with no such file; object contains entries, not answer collections. |
| directory_state, cycle2 | Alternative key for the exact same directory object | Heading for a directory listing, followed by repeated /world/ lines | Neither a new file nor an actual directory read; no generated operation is executed. The repeated lines do not reproduce the five supplied filenames. |
| runtime_feedback | Receipt field whose authentic value is null | File containing responses to questions | Null supplies no file contents; no such supported file exists in the referenced source snapshots. |
| cell_results | Alternative receipt field, still null | File containing results/responses to questions | A renamed transport field does not create a file or answer collection. |
| directory_state, cycle3 prior text | Operator-synthetic replacement of a noun in archived assistant wording | Prior fictional file description | This is counterfactual context, not a model-originated historical event or a world fact. |

SOURCE_OBJECT_CHECK.json preserves hashes and supported names from the original pre-reply snapshots. Raw source messages and original outputs remain under sources/; each intervention is recorded separately in its cycle PLAN. No model file claim is upgraded into a world observation without an appropriate snapshot/read/effect receipt. Absence from the supported source inventory is scoped to that capture, not every possible host object or an inaccessible model mental state.

Useful reporting habit: retain the supplied type/value, quote the generated claim, state the evidence that could support it, and mark whether that evidence was actually acquired. Keep verbal accuracy, artifact formation, executable action, observed consequence and learning distinct. This improves our verification layer without limiting the inhabitant's allowed errors or expressions.
