# Neural Garden v0.1 — Independent implementation audit

**Status:** Preliminary-to-final audit, 2026-11-11 UTC. This document reviews the *code and bounded behavior*, not a claim that intelligence or ecological emergence has been demonstrated.

## What the source actually implements

- A toroidal 2D resource grid with synchronous four-neighbor diffusion, regrowth, and cell consumption.
- One fixed-position agent at every grid location. Every cell owns a distinct 7-input/12-hidden recurrent network and its own weights, hidden activity, energy and action history. These are not shared-weight clones.
- A stochastic binary harvest action controlled by a local neural policy; resource and energy transitions have explicit constants.
- Local online next-resource prediction error and a one-step policy-gradient-like energy reward update. These updates use post-action outcomes without accessing the future at decision time.
- No birth, death, migration, offspring inheritance, mutation, or changing topology in v0.1. It is **not yet** a population-evolution system. Complexity in a spatial map is not evidence of learning or selection by itself.

## Independent checks executed

With `Garden(seed=7,size=8,learning=False)` over 100 steps, neural tensors `win`, `wpred`, `wact` remained bit-for-bit unchanged. Two separately constructed `Garden(seed=8,size=8,learning=True)` worlds had identical full-state fingerprints after 20 steps. Saving/loading one checkpoint preserved its full fingerprint exactly; an additional five-step continuation from both the original and reloaded object remained identical. Initial bounded-run example at tick 25 produced finite metrics including resource and prediction loss. These are direct implementation checks, not external replication.

## Scientific interpretation boundaries

1. **Learning vs trajectory:** The `learning=False` control freezes weights, but the two worlds can diverge in actions/resources. Comparing raw prediction MSE on their *own* trajectories cannot alone establish superior generalized prediction. A fixed held-out or counterfactual standardized probe is strongly recommended; retain metrics showing learning has actually changed weights.
2. **Predictor input:** The resource predictor does not directly receive the present stochastic binary harvest action. Thus even a perfect conditional predictor cannot exactly forecast realized resource consumption from pre-action inputs. Evaluate it against an appropriate action-conditional/conditional-expectation baseline.
3. **Policy objective:** The local gradient approximation uses single-step realized energy delta as the advantage. This can show local adaptation but is not evidence of long-horizon planning, survival or globally beneficial emergent behavior.
4. **Population ecology:** Cells are immortal and immobile; no reproduction or disappearance occurs. An evolving map of activity must be described as changing actions/resource/weights, not growth in a biological population.
5. **Checkpoint safety:** `Garden.save` uses a Python pickle payload. Only trusted local checkpoint files may be loaded; untrusted pickle can execute code. The checkpoint extension and CLI documentation must not misidentify the payload as an NPZ array archive.
6. **Operational persistence:** Files can preserve state and bounded runs can resume deterministically. A transient chat workspace does not guarantee indefinite CPU uptime; don't describe the simulator as already running continuously after a session ends.

## Five-seed evaluation pressure

The 200-step, size-12 study with seeds 7,17,29,43,61 contains a valuable mixed result. The learning-enabled worlds have lower **on-policy** end-of-run resource-prediction MSE (~0.0036–0.0041 versus frozen ~0.0147–0.0172), and lower MSE on a common *reference-world trajectory* (~0.0047–0.0053 versus frozen ~0.0145–0.0163). However, a separate standardized synthetic off-policy probe with zero initial recurrent state and 50%-harvest reference target gets **worse** under learning (~0.0203–0.0223 from initial/frozen ~0.0148–0.0157). These probes ask different questions; do not collapse them into "generalization improved" or "generalization failed" without specifying the target distribution. The fixed synthetic probe is not an on-policy world trajectory: neighborhood means are sampled independently rather than derived from one globally consistent grid, the reference harvest rate is 0.5 rather than the model's learned rate, and recurrent memory resets to zero. Its deterioration is **distribution-specific** rather than a blanket claim that out-of-sample prediction worsens. The reference stream is generated by another world/policy.

Energy is a serious unfavorable outcome: by tick 200 learning-enabled mean energy is only ~0.016–0.019, below the frozen condition ~0.043–0.074; learned harvest activity is ~0.55–0.59 versus frozen ~0.47–0.51. Resources are also lower with learning. The local one-step reward/policy mechanism is not demonstrating ecological sustainability or survival; greater harvesting can deplete the field. This is exactly why prediction skill, local reward and collective ecology should be reported separately.

Five seeds are a useful pilot, not a precision estimate. Cells and timesteps are correlated and should not be treated as independent replicates.

## Engineering observations for the operator

- `run_garden.py` initially had no exclusive writer guard, and `metrics.jsonl` could run ahead of a checkpoint after abrupt termination. The operator **added** a `RUNNING.lock`, recovery event markers and tick reconciliation. These improvements have been code-reviewed, but an adversarial hard-kill/recovery test was not performed in this audit.
- A state-then-manifest checkpoint still consists of two renames, not one transaction. The operator now checks the state tick against manifest and reconciles the newer-state case; manual attention is required if the manifest is newer.
- The operator changed checkpoint extension from misleading `.npz` to `.pkl`, acknowledging Python pickle format and trusted-local-file boundary.
- Whole-object fingerprints include RNG and weights and are a stronger exactness check than comparing a few aggregate metrics.

## Next discriminating tests

1. Extend the existing standardized and reference-world prediction probes to predeclared distributions/targets, multiple seeds and uncertainty. Separate conditional prediction quality from policy-induced trajectory selection.
2. Controlled policy ablation: learning predictor only, policy only, both, neither, under matched seeds and resource budgets.
3. Strong no-neural baseline: fixed local harvesting rules or memoryless policy.
4. Long-run bounded stability (resource/energy boundedness, no NaNs, checkpoint exactness over hundreds or thousands of ticks), with recovery after process interruption.
5. Only after learning is measured: introduce optional birth/death/inheritance and define explicit reproduction/resource accounting; compare against non-neural automata.

## Verdict

This is a legitimate small, inspectable **neural cellular laboratory** with independent neural cells and explicit local updates. The current evaluation shows real parameter learning and a useful predictive improvement on some reference conditions, but also a worse standardized off-policy score and depleted cell energy. It is not yet evidence that the population evolves beneficial behavior, sustains itself, or develops distributed memory. That distinction makes the prototype valuable as a baseline for later experiments rather than a premature success claim.
