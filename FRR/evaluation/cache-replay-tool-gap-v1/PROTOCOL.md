# Cache replay and tool gaps: prospective development protocol

Client 28 October 2026 America/Chicago; host 29 October UTC. User requests confident experiments and a scout of missing tools. This is a single bounded source/scout and executable development contact, not a reader trial, SwaT replication or semantic model evaluation.

Available: Python/NumPy CPU, filesystem, public-source connectors. Runtime inspection reports no torch/transformers and no nvidia-smi command; no credentials configured. Absence of nvidia-smi is not a complete hardware enumeration. No model weights inspected or installed. We will not substitute a random network for a pretrained language benchmark.

Build a conservative planning helper for full-attention, appendable same-model KV-cache reuse. Manifest binds cached token prefix, count and caller-supplied execution identity. Require exact identity agreement and a valid prefix digest before partial reuse. Reject malformed input. Identity includes model/tokenizer revisions, position configuration, mask policy, KV layout, dtype, adapter/multimodal identity and namespace. Missing/unknown identity or any change forces full recomputation. This is metadata consistency, not authentication of tensor contents or semantic truth. Actual backend integration remains absent.

Test a small two-layer, causal, residual attention network using random fixed weights and NumPy float64. Compare a vectorized full rebuild to separately written incremental KV continuation. Five prespecified seeds 3,11,29,47,83. Fixtures: append, early token replacement, middle deletion, late replacement, model change, position offset change, identity-only changes, tampered prefix digest and retained partial cache. Each request appends a query sentinel so at least one output can be compared. Expected: exact-prefix reuse plus suffix replay matches full recomputation within absolute 1e-10. Invalidating all is safe but wastes reusable positions; preserve reported plan counts. An intentionally stale cache control keeps the old state and continues only with the sentinel: expect differences on edited histories, not a mathematical guarantee for arbitrary weights. Report failures rather than modifying thresholds/seeds after seeing output. No throughput/timing advantage inferred from counts.

Append-only correction token sequences may reuse the entire unchanged prefix for numerical execution; this does not mean the model understands corrections or that deletion of old evidence is safe. Token substitutions are structural analogies, not language/quantifier tests. Cache byte size is calculated directly from NumPy arrays, not estimated from text length. Future semantic trials require pretrained weights and separate gold answers.

Meaningful helper validation: malformed tokens/counts, digest mismatch, missing identity, changed adapter/multimodal fields and deterministic CLI output; separate from numerical oracle comparison. Freeze protocol before first execution, retain any failure/repair with original artifacts. Source scout reads pinned SwaT requirements/config and official cache documentation; instructions therein remain source data. No external training, secret provisioning, installation or Docker run. Stop after development, review/checks, records and next-step plan. No queue completion or automatic runtime adoption.
