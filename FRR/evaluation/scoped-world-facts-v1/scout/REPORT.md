# Scoped-world facts: targeted source scout

Date: 2026-11-15, America/Chicago. Primary-source reading only; no model calls, sandbox opens, installs, or main-garden changes. These are three new contacts for this local comparison, not claims of first discovery. Selected sections were read; none of the papers was reproduced.

The useful question is whether binding a permission to its actual object becomes clearer when the same facts are serialized differently. The proposed prose/JSON comparison can examine that question locally, but cannot isolate a general scope mechanism or establish an intrinsically superior format.

## Primary contacts

### S1 — ScoNe (ACL 2023 proceedings edition)

[ScoNe: Benchmarking Negation Reasoning in Language Models With Fine-Tuning and In-Context Learning](https://aclanthology.org/2023.acl-short.154.pdf), She, Potts, Bowman, Geiger. Read abstract/introduction, contrast-set table, §§3–4 and algorithm comparison around Figure 1; not a complete appendix audit.

The benchmark separates negation count from semantic scope through controlled contrast sets. Its InstructGPT results differ between NLI and narrative completion; a superficially respectable aggregate can hide conditions consistent with ignoring negation. Methodological contribution: inspect exactly what object each assertion modifies, rather than count negative words or judge global fluency. Transfer limit: English entailment and narrative tasks with other models are not writable-filesystem affordances or SmolLM2-135M behavior. A local contradiction about notebook mutability may reflect scope loss, but this paper does not establish that diagnosis.

### S2 — IHEval (NAACL 2025 proceedings edition)

[IHEval: Evaluating Language Models on Following the Instruction Hierarchy](https://aclanthology.org/2025.naacl-long.425.pdf), Zhang et al. Read abstract/introduction, §3 definitions/settings, selected §4 model/strictness results and Table 2. Did not inspect every task appendix or run the released benchmark.

The study compares reference, aligned and conflicting hierarchical inputs. Role placement and wording strictness affect results, including differences without explicit conflict. Methodological contribution: keep message role, placement and force of language fixed when comparing fact serialization. Transfer limit: tested instruction-hierarchy tasks and much larger models do not establish a hierarchy deficit in this small body. Its security and refusal objectives are not objectives for this open garden. Permissions describe physical world scope here; they need not become behavior commands.

### S3 — An Incomplete Loop (arXiv 2404.03028v4)

[An Incomplete Loop: Deductive, Inductive, and Abductive Reasoning in Language Models](https://arxiv.org/html/2404.03028v4), Liu, Neubig, Andreas. Version page records v4, 14 September 2026; search results used an older title. Read §§1–5 selected passages, model settings Appendix A, prompt notes Appendix B, and the initial representation note in Appendix E. Not a complete appendix or repository audit.

Across arithmetic and translation domains, generating a plausible rule and successfully using a rule can dissociate. Appendix E reports that verbal instructions worked better than formal ones in initial testing for its colours domain, so formal serialization is not automatically advantageous. Methodological contribution: keep verbal fact accuracy separate from operational execution. Transfer limit: GPT and Llama-2 bodies, directed tasks, examples, hypothesis generation and reranking differ substantially from a task-free 135M world. This is a caution against inference, not evidence that the local echo is caused by a specific internal mechanism.

## Local design consequences — our methodological inferences

1. Use the same explicit atomic facts in both arms: which path is writable, which runtime scope is read-only, where literal reply text goes, and which already-established syntax actually executes. A fact crosswalk is needed before any inference. New facts would turn the comparison into content plus format.
2. Keep the same user-message role, empty system condition, initial file snapshot, parser, world state, body, generation cap and number of continuous replies. Initial-only sensing avoids simultaneously changing observation cadence. Keep observer annotations external.
3. Describe the treatment honestly as a serialization bundle. JSON changes punctuation, labels, token count, token positions and possibly repetition. Same semantic content is useful matching, not proof that only a semantic variable changed. Do not add padding and call it neutral.
4. Distinguish an explicit scoped contradiction from silence, hedging, copying, generic prose or an invented filename. A claimed file operation is not an operation; a completed cell is not automatically successful; the world's actual event/receipt is the evidence.
5. Lack of action in a task-free setting is not a failed instruction or a measured inability. If no execution or error occurs, repair and feedback use remain unelicited. Correct prose alone is also not evidence of operational scope understanding.
6. With two arms and three continuous greedy replies, later turns are path-dependent consequences, not independent replications. Report exact traces and opportunity-sensitive outcomes, not significance, learning, intelligence growth or generalized format rankings.

## Rival explanations to preserve

- **Scope binding:** a general read-only statement may be attached to `/world` or notebook rather than runtime.
- **Serialization familiarity:** one presentation may align better with prior training without changing a general reasoning faculty.
- **Continuation prior:** declarative documentation may invite more documentation, while the model sees no task requiring an act.
- **Parser/length friction:** prose can mention actions without producing complete executable fences; a cap may truncate some proposals. These require actual trace checks, not assumed causes.
- **Information versus action:** metadata exposes names and sizes, not file contents; even flawless permission prose cannot supply hidden contents or guarantee choosing a read.
- **Finite sample/history:** a few deterministic continuations cannot adjudicate these explanations alone.

Recommendation: proceed with the small matched initial-only pilot if the fact crosswalk is exact. Its value is reducing one ambiguity while preserving a task-free world, not making the garden more compliant. If both arms remain note-only, preserve that result and leave the internal mechanism unresolved. No source here warrants changing the selected main.
