# Concrete object reference and an evidence question

17 November 2026, America/Chicago. Eight actual new cached-model calls, with fixed weights and unchanged byte-world physics. Four initial branches compare an ambiguous reference with an explicit filename; four subsequent calls compare factual-only continuation with an open evidence question from matching copied checkpoints. Every earlier garden remains preserved.

## Main result

Naming field.bin changed the topic of the answers, but did not reliably ground them. An open request for supporting/challenging observations elicited evaluation-shaped prose, not demonstrated evidence checking. No executable actor cell or model-created artifact occurred in any new call. Some individual facts were correct; other claims were contradicted or unsupported. These findings do not establish absence of reasoning, general inability, or a need to train weights.

## What was held fixed and what changed

The cached pretrained SmolLM2-135M-Instruct, exact compact FRR, literal Python/shell execution interface, initial62-byte file and changing local XOR law were unchanged. Temperature0.8/top_p0.95, CPUfloat32/eager/two threads and a256-token generation ceiling were fixed. Every history retained actual native roles and private sampling RNG state. There was no training, optimizer, teacher, repaired source, semantic reward, best-of selection, context pruning or output-dependent retry. Model parameters were digest-checked before each stage, after each call and at stage completion. No model download or paid model endpoint was used.

The tested directly bounded run-length sensor was used throughout. A declared timing-neutral receipt view was activated for ALL new branches: stdout, stderr, exit status and resource boundary remain literal; only wrapper-measured elapsed seconds are omitted from model-facing metadata. Complete raw receipts, including seconds, remain external. The same mechanical disclosure was added to every initial system context. Thus this is a fresh observation-policy contract, not an exact replay or modification of older prompts. The policy does not sanitize a model's own stdout or make execution universally deterministic.

The paired followup design avoids the previous cross-study timing nuisance: both siblings inherit the exact same first history, and their model-facing receipts omit wrapper durations. Audits check matching histories/world/RNG before the question. This gives a cleaner local comparison, but two seeds and one followup per pair cannot establish a population effect or lasting improvement. The initial wording difference also changes tokenization and length; do not attribute the result to semantic object understanding alone.

The broad questions allow answers from supplied facts without tool use. Zero actor actions is therefore not sufficient to declare an answer invalid. Here there were no artifacts or demonstrated investigation, and specific factual claims could be compared with known states. Ground truth is available independently of fluent descriptions.

## Confidence update

**High, scoped to this run:** exact filename wording affects topical response; an evidence question can elicit evidence-shaped headings without demonstrated verification; copied-checkpoint comparisons and timing-neutral receipts provide cleaner experimental control; the world and external records preserve actual consequences.

**Not demonstrated:** reliable factual checking, self-directed file use, artifact-based organization, contextual learning or sustained cultivation. No FRR efficacy estimate follows because every condition used the same FRR. Some correct facts occurred alongside errors; do not summarize the model as uniformly incapable or uniformly grounded.

**Still open:** whether a different interaction style, reduced context burden, better elicitation, a different body or eventual training is needed. No weight change is required to continue diagnosing these possibilities, and this experiment does not establish that weight training is necessary or sufficient.

Confidence that another broad metacognitive prompt is the strongest next step has decreased. Before adding conversational scaffolding or widening autonomy blocks, calibrate prerequisites in explicitly separate diagnostic copies: can this body read the actual byte count, identify a single observed state change, and deliberately issue one valid existing action under a clear request? These tests would distinguish fact extraction, temporal comparison and actuator elicitation; they would not be solutions or corrections inserted into a preserved free-world trajectory. Conditional file-use success under older prompts remains relevant, so the question is proficiency under the present context, not universal inability.

No new calibration call, weight update, physical-law change or wider continuation is queued. The gain is measurement clarity: asking, answering, adopting a critique format, checking a fact and acting are separate observable events.

Garden translation: naming the plant got the gardener talking about the plant. Asking for evidence produced the shape of inspection, but the ledger still showed no inspection of its own. The next useful work is to locate which small bridge is missing, while leaving this season intact.
