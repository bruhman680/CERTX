At10000, diverse calibrated designs give a singleton set for all800 fixed-candidate assessments in each known/estimated mode. Redundant designs give400/800 singleton sets, while remaining unable to allocate arbitrary two-component contributions. Estimated-calibration continuous intervals average .159 wide in each coordinate even when the four fixed candidates separate. Lower budgets are mostly unresolved. All true candidates/continuous truths are retained in this saved simulation, using deliberately conservative Hoeffding bounds; this is not proof of100% future coverage.

The key review observation:2338/2400 estimated redundant matrices look numerically rank2 despite a stipulated rank1 population design. Structural abstention, not numerical inversion or pooling alone, prevents a false generic allocation. Missing calibration returns an unassessed set by policy; it does not prove all known worlds equivalent.

Across datasets the statistical budget is213120000 Bernoulli-equivalent trials, sampled as aggregate binomial counts. These are not tool calls or actual hardware resets. Computation was local and small; preparation/real instrumentation costs are not modeled. One stochastic run and one deterministic sufficient-statistic replay; no discarded sampled datasets. Exact gzip archives preserve raw results/counts, with restore instructions in Cycle1's report.

## What the harness did, and did not establish

We observed declared budgets, fixed criteria, explicit abstention, adaptive rival selection, review-discovered faults, repair with original preservation, and current-record updates. The missing-rank guard and invalid-input faults also show limits in initial verification. These observations help inspect this run's process; without a comparison/control and broader repetition they do not show that FRR improves reasoning or establishes durable habits.

Witness correctness, access loss, unknown reset targets, state-dependent intervention laws, sampled interaction inference, and actual-agent transfer remain open.
