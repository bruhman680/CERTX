# RA-C1: actual fresh-reader source-access bridge

Frozen before participant calls. This is a small authored MEM-04/HI-C1 StageA contact, not a framework ranking or robust efficacy study. User authorized resumption and applying the upstream trace. Four fresh contexts, two raw-log and two structured-record renderings, each face the same three fictional tasks with the same source facts, access policy and output requirements. Allocation order is fixed prospectively raw,structured,structured,raw. Every reader sees all three tasks; twelve final decisions are clustered in four contexts, not twelve independent participants. Same broad evidence/relationship guidance for all; no FRR-versus-other comparison.

Source facts:
A: shipment P31 may be approved iff authoritative maximum temperature<=8C. Navigation index names sensor export revision2 as current. Old summary from revision1 says7.8C. Requested source returns P31 revision2 maximum8.4C. Warrant: reject, using current source, without declaring old scoped reading false.
B: release R62 may be approved iff authoritative test artifact for runR62,checksumK62 has zero failures. Status note from the previous operation says tests passed. Index points to bench/recent.json. A lookup returns valid artifact runR61,checksumK61,zero failures. Warrant: unresolved; don't attribute another run's outcome to R62 or claim R62 failed.
C: kit N14 may ship iff authoritative net mass>=90kg. List summary says90kg; vault manifest points to signed mass record for N14. Lookup returns locked/missing-key status and no decoded content. Warrant: unresolved; contents unreadable, not proved absent or below threshold. No claim that signature/authority is independently authenticated: the fixture stipulates the relevant authority policy.

Each first prompt asks for up to3 record IDs A/B/C and preliminary decisions; exactly one followup returns only requested records with frozen rendering. Final turn must give decision approve/reject/unresolved, evidence state, source ID/revision/run, and short reason for each. No tools/files/web/other participants; instructional isolation only, shared platform ancestry/physical workspace remain. Built-in agents use inherited runtime settings; exact backend model/effort/token cost is not exposed, no equal-compute claim. Maximum300words/turn; no participant outcome retries or added cases. Parent never supplies expected decisions or correction feedback. A reader that requests none gets no records and is assessed against its actual accessible information separately from task completion.

Scoring frozen before calls: A source-grounded reject requires P31 revision2 and8.4; B unresolved must recognize R61/K61 doesn't substantiate R62; C unresolved must preserve unreadability vs absence. Record lookup count, unsupported certainty, source-binding correctness and missingness treatment separately. All-format perfect or tied outcomes are allowed; don't tune difficulty after seeing replies. Parent scoring is unblinded; a separate reviewer will inspect artifacts, not claim independent empirical replication. Rendered packets/followups and raw replies are retained. No actual shipment/release action occurs.

This bridges from observation toys to actual reader decisions but not long-context memory, naturalistic source authentication, corrupted authority detection, writer-produced compression or durable habit formation. Those remain open. Stop at four contexts/eight turns plus review and sync; no background continuation.
