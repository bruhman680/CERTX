# Prospective conceptual note: optional saved-output hybrid replay

Root proposed a secondary replay while primary inference was underway; reviewer has not inspected any new outputs. This is outside the frozen independent-query primary design. A separate post-hoc/prospectively frozen replay protocol should be recorded if executed. This note is not evidence that the replay ran.

Concept is useful without a blocking logical defect: parse only an exact number plus correct unit from each of the independently generated measurement/minimum responses (or exact MISSING for measurement), then apply the deterministic comparator to those generated claims. Do not replace generated quantities with evaluator/source gold. Keep unparsed claims unresolved. This consumes information from two generation calls, whereas a direct pass answer used one; it is not an equal-information, equal-cost or pure instruction comparison.

Parser acceptance certifies only syntax under the specified parser. Caller run-to-prompt association supplies record identity/unit context; the generated response itself may not establish entity or source binding. The comparator can be correct conditional on false generated inputs. Preserve raw claim, parse decision and reason, compared quantities, computed status and evaluator-only correctness of each extracted source fact separately. Oracle fact correctness may evaluate full warrant but must not silently gate the actual replay calculation or repair its inputs. Right status from wrong values is not fully warranted.

An exact MISSING output is a model claim, not a trusted fact. It may yield UNKNOWN when an actual measurement exists; preserve and score this. If the minimum fails to parse while measurement is MISSING, a policy of requiring both parser results can abstain, but the report should identify that conservative implementation choice: missing measurement alone already blocks a known threshold comparison. Rejected/unresolved records remain in the denominator, with reasons; do not report only accepted cases. If external executable checker enforces units/identity/hash, these checks still do not authenticate the source or make a hallucinated quantity true.

Freeze replay algorithm/parser/metrics before calculating replay outputs. Keep primary raw, scores, keys and contract unchanged. No additional model learning or internal-pipeline mechanism conclusion follows from this replay.
