# Saved-array schema

All NPZs use `allow_pickle=False`; arrays are numerical, boolean or Unicode strings. No object arrays. Row vectors apply column projectors as `x @ P.T`, including complex vectors.

`source_inputs.npz` is the exact predecessor NPZ, byte-identical and archive-bound. Source keys retain `s{seed}_...`; only dense rotation `s{seed}_Q[1]` is used. Record order is entity, time, A/N/U; claim index is entity*2+time. Evaluation record banks have48rows, calibration24, queries32 per r/eta. Source query claim/repetition arrays are authoritative. Query IDs are `{seed}-r{ri}-e{ei}-q{j:02d}`. r0=.5,r1=2; e0=0,e1=1.5.

`training_inputs.npz`: prefix `s{seed}_`; master_seed scalar; stream_spawn_keys(3,1), stream order context/binding/mismatch. Each `{context,binding,mismatch}_{raw,unit}` is(1024,12). Rows0:768 fitting,768:1024 validation. Arm a0 CLEAN delta0; a1 INDEPENDENT_0.5; a2 INDEPENDENT_1.5; a3 ALIGNED_0.5; a4 ALIGNED_1.5. `{prefix}a{ai}_pairs` is(1024,2,24), unnormalized A/N members; `_differences` is(1024,24), base coordinates. Aligned arms use binding_unit as mismatch, while independently generated mismatch_unit remains saved.

`structures_centres.npz`: `{prefix}full` and `oracle` are(24,24). `{prefix}a{ai}_pairs_rotated` and `_differences_rotated` preserve actual training geometry. `_population_moment` and `_population_target` are(24,24) in dense coordinates. For stem `{prefix}a{ai}_m{m}`: `_projector`(24,24), `_basis`(24,12), `_singular_values`(min(24,m),), `_empirical_second_moment`(24,24), `_empirical_eigenvalues`(24,), `_population_principal_cosines` and `_binding_principal_cosines`(12,). Additional `_training_residuals`(m,24), `_validation_residuals`(256,24) contain D-PD.

Calibration stem `{prefix}a{ai}_m{m}_r{ri}_{method}`, method lower-case full/oracle/estimated: `_centres`(3,) complex circular means (modulus concentration); `_available`(3,) bool; `_calibration_products`(8,3) contains actual matching entity/time products; `_calibration_valid`(8,3); `_calibration_query_norms`(8,), `_calibration_record_norms`(24,). Centres fit clean cal A rows against same-scope A/N/U only. Every fit saved before evaluation scoring.

`outcomes.npz`: append `_e{ei}` to calibration stem. `_products`(32,48) normalized complex inner products; `_valid`(32,48) combines projected norms and product magnitude threshold; `_labels`(32,48), `_reasons`(32,48); `_top`(32,3) stable descending modulus ranking; `_query_norms`(32,), `_record_norms`(48,). Labels A/N/U/ABSTAIN; reasons ok/zero_product/ambiguous_centre/calibration_unavailable. Global unavailable calibration takes priority. Scores are abs(products), angles angle(products); invalid angles are never evidence for labels.

`LEDGER.jsonl` has23040method records, each condition(seed,Q=dense,arm,delta,kind,m,r,eval_eta,method), query_id/index/claim/repetition, outcome_key, returned_indices/record_ids/scores/angles/predictions/reasons, boundary_gap/near_boundary_tie, within_top3_score_differences, oracle_relevant_predictions/reasons, metrics. Scores sort exact numeric values; tie flags never alter ranking. oracle_relevant is diagnostic, never inference input. Metrics include predecessor metric names plus evidence_count and joint_label_count. Wrong scope means either wrong entity or wrong time (claim index differs). `PAIRED_ROWS.jsonl` has7680rows with method_record_indices into ledger. `AGGREGATES.json` has720conditions, count32, metric_sums/means.

`STRUCTURAL_DIAGNOSTICS.json` has60rows, one per seed/arm/m; `POPULATION_DIAGNOSTICS.json`15rows; `ALGEBRA_DIAGNOSTICS.json` contains raw rotation and calibration channel checks; `PRODUCT_CHECKS.json`720actual evaluation channel checks. `PREDECESSOR_CONTROL_CHECKS.json` compares every dense FULL/ORACLE predecessor record across all six previous supervision conditions, retaining every metric difference. `REPEATED_CONTROL_CHECKS.json` compares FULL/ORACLE across the20new training settings. `QUERY_MANIFEST.json`384IDs,288unique base arrays,48underlying claims.

INPUT_MANIFEST contains original and used-array hashes and training bank hashes before SVD. PRE_SCORING_CHECKPOINT binds fitted arrays, structural/population diagnostics and query manifest before outcome scores. OUTPUT_HASHES binds all output files except itself. ATTEMPT starts before work and becomes complete only at successful end. Failed nonempty outputs are never overwritten.

Structural JSON field names are `difference_numeric_rank`, `retained_rank`, `rank_tolerance`, `singular_values`, `rank_cutoff_gap`, `rank_cutoff_near_tie`, `empirical_eigengap`, `population_eigengap`, `moment_operator_deviation`, `distance_to_population_target`, `distance_to_intended_binding`, `population_principal_cosines`, `binding_principal_cosines`, `hermitian_error`, `idempotent_error`, `projector_rank`, `train_relative_residual`, `validation_relative_residual`, alongside seed/arm/delta/kind/m. Relative residual denominators are sum|D|² over the matching training prefix or separate last256validation rows; numerators sum|D-D@P.T|². Moment deviation uses spectral/operator norm; distances use Frobenius/sqrt24. Population JSON also includes `population_gap`, `target_rank`, `target_hermitian_error`, `target_idempotent_error`, `population_target_distance_to_binding`, `analytic_distance_to_binding`, `difference_identity_error`, `common_context_identity_error`, `rotation_difference_error`, and descending `population_eigenvalues`.
