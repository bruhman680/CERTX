# AS-C2 design refinements — proposals only

These extend, rather than replace, the preserved AS-C1 drafts. They are not frozen experiment protocols or executed tests.

## First contact: active discrimination with uncertain instruments

Keep intervention diversity separate from repetition count. Before selecting probes, enumerate response-probability regions across plausible reset success, off-target effects, initial-state mixture and readout parameters. Select for worst-case rival separation, not nominal effect size. Include a faulty instrument, a faulty process, both and a candidate-family misspecification case. Carry calibration uncertainty into the verdict. Overlapping regions justify unresolved; rejecting every candidate must not automatically select the least-bad model. Finite sampled outcomes require an explicit error-control rule; borrowed deterministic diagnosis guarantees do not supply one.

## Later compression contact: task-and-loss transfer

Use one fixed source and explicit raw/compressed representations. Include common details and a rare action-changing exception. On a small finite source compute ideal attainable decision risk; separately test a fixed bounded reader with declared access/cost. Measure reconstruction error, exception retention, decision regret and appropriate withholding separately. Switch the downstream task or error cost after the summary is fixed. If raw retrieval differs between arms, treat it as a separate access intervention. Low weight-matrix error, readable prose or distributional similarity does not itself certify the right decision.

## Later collective contact: influence versus channel structure

Save initial reader answers before communication. Under the same evidence, access and communication budget vary only the cue accompanying peer answers: popularity/repetition, independently scored past performance plus freshness, or neutral identity. Evaluate on new items and introduce reliability shifts. Log who could see each source separately from how answers moved; citations are only an imperfect indicator. Report correctness, dependence/tail failures and cost, not consensus alone. Do not label human-social results direct evidence about model agents.

## Current practice: progress, acceptance and evaluator change

Retain partial progress as useful evidence, while checking completed artifacts against the declared task contract. Reassess inherited evaluation assumptions when the task, policy or representation changes. This is already compatible with the verification/reopening modules; no new core command or universal completion gate is installed. Exploratory questions need not be treated like tasks with a single binary success condition.

Protected checks certify their coverage, not everything one hoped they measured. A phase-local reward or a lower reconstruction loss cannot substitute for a separate task outcome. Preserve prior snapshots and evaluate proposed changes against reserved cases before using those outcomes to select another improvement.
