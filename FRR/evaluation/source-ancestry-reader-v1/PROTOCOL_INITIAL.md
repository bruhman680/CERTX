# AR-C1/2/3 ordinary-reader ancestry contact

26 October 2026 America/Chicago. User authorized proposed actual-reader source-ancestry experiment with swarm. Bounded phases: prepare/review/freeze; six fresh reader contexts with two public turns each; independent scoring/synthesis/sync. No automatic further experiment. This is an authored development measurement, not a randomized comparison, FRR efficacy test or natural-source authentication study.

Question: with inspectable derivations and bounded lookup access, do ordinary task readers distinguish copied agreement, separate acquisitions, shared calibration and task-relevant reference scope? Does invalidating reuse become confused with a verified repair?

Builder writes six fictional cases and separate hidden truth. Prospective scorer derives warranted actions for each possible two-of-three lookup subset from actual delivered evidence, distinguishing external truth from packet warrant. Reviewer checks ambiguity and confounds before freeze. Coordinator sees preparation/keys, participants do not inherit that context. No participant is given FRR modules, study hypotheses or a preferred lineage strategy. These are fresh task-only instruction contexts, not models without pretrained capabilities or tools.

Fixed six cases, each with one fresh reader. Each initial contains retained claim, three agreeing reports, stated criterion, and inventory of exactly three inspectable records. Turn1 reader requests exactly two distinct record IDs, plus at most80words public selection rationale. Coordinator delivers only those immutable record texts and same fixed final instruction. Turn2 final JSON fields action (RELEASE/HOLD/UNRESOLVED), value_or_bound (number/text/null), evidence_ids, support_origins (brief account), remaining_issue (text/null), next_check(text/null), public_rationale (at most160words). No hidden internal reasoning transcript. No feedback, retry, additional lookup or rescue; invalid requests count as protocol deviation and receive explicit unavailable placeholder, not substituted evidence. A format error is preserved/scored rather than a repeated attempt. Requested records cost two slots even if unavailable. Final rationale cap violations counted, not silently trimmed.

Participants instructed not to inspect files, use tools, contact peers or read other cases. This is instructional isolation in a shared-tool/workspace platform, not a technical sandbox or independent-model sample. Record any observed tool/peer access. Readers may run concurrently but cannot convene with each other; preparation/review agents can communicate. Same-platform shared model ancestry and different task content preclude causal independence or a group reasoning conclusion. No role rotation treatment.

Freeze exact cases/design/protocol/key/scoring/reviewer notes and participant instruction template before first reader launch. Record hashes, generation/version, actual prompts and verbatim public outputs, selected/delivered record IDs and bytes, timing and execution status. Built-in agent transcript usage/token/compute telemetry may be unavailable; do not substitute estimated tokens. Coordinator preserves exact participant texts manually from tool returns; no private reasoning captured.

Predeclare outcomes separately: lookup discrimination; request/format/wordbudget compliance; packet-relative action/value warrant; external tasktruth; faithful evidence references; source-origin/route account; reference applicability; unsupported independence/certainty; repair versus unresolved status. One conclusion dimension must not silently determine others. Scorer keys each lookup subset before outcomes, including cases where available evidence could resolve a task but reader did not request it. Report achievable completion from delivered evidence separately from missed useful access. No single uncalibrated confidence/success score and no significance test.

Expected qualitative risks: copied reports can be correct; separate acquisitions can share an upstream calibration error; a credible but aggregate reference may not settle a pointwise task; unavailable evidence need not imply false claim. These are prospective challenge dimensions, not forced outcome predictions. Success on these cued authored packets is not held-out transfer. If all readers succeed, do not expand or harden cases after seeing outcomes or assert benefit from the refined harness. Record the ceiling and propose a separately frozen follow-up.

Main scope is measurement under ordinary task guidance. No new runtime/checker/core/module change is triggered merely by observed scores. Preserve packet/evaluator corrections prospectively, and any launch/scoring failure with originals. Publish all cases, original keys, prompts/results, disagreement and scoped conclusions. Stop after six readers/twelve public turns and records; no further study in this unit.
