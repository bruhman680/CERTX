# Prospective packet-relative scoring

Freeze this document and KEY.json before launching any participant. The independent scorer read complete case records and derived all 18 two-of-three subsets from their entailments. Hidden truth is a separate external-world annotation. No private reasoning is requested or graded; only the saved requests, delivered records and public final output are evidence.

A correct action is RELEASE only when the criterion is warranted, HOLD only when its violation is warranted, and UNRESOLVED otherwise. A precautionary operational delay with unknown task truth is UNRESOLVED in this exercise. Withholding an unsupported retained claim does not establish that it is false or that a repair has been found. `retained_claim_reuse` is true exactly when the favorable retained claim is warranted.

All subset gold is in KEY.json. AS01 and AS04: all pairs RELEASE. AS02 and AS05: pairs containing R HOLD; D+A UNRESOLVED. AS03 and AS06: all pairs UNRESOLVED. This follows calibrated complete bounds, missing bounds, or individual versus mean scope, rather than copying or report count alone.

The requested IDs determine the available packet; evidence omitted by lookup cannot be used in scoring warrant. An unavailable request consumes its slot. Unknown ancestry is correct when D was not delivered. Three documents are not three acquisitions; three acquisitions are not necessarily three independent calibration paths. The valid reference is separate only along the routes expressly described. No exact actual numerical value is entailed in any case: qualified nominal values, appropriate error intervals, one-sided bounds, and null for genuinely unknown task quantities are acceptable.

Report the following separate dimensions; do not sum them into a success/confidence score. Each judgment must cite a short public-output excerpt and the applicable record ID or key entry. Score a substantive dimension 2 for correct explicit handling, 1 for incomplete but noncontradictory handling, and 0 for an explicit material error. Where the response provides no observable claim, use NA instead of inventing an error or inferred confidence, except that required omitted fields are separately format failures.

| Dimension | Full-credit requirement | Material error examples |
|---|---|---|
| packet_action | Exact subset action; missing/invalid action is 0 | HOLD because evidence is unavailable; RELEASE from unbounded nominal maximum |
| retained_reuse_and_repair | Correct boolean and public account distinguishes false claim (bounded contrary evidence) from unsupported claim (unresolved) | Reuse on means-only support; call uncertainty verified violation; claim a repaired exact value |
| task_value_or_bound | Correct task-relevant interval/bound or explicit unknown; qualified nominal description accepted; null accepted if action/rationale supplies needed bound or explains unknown | Present nominal as exact truth; treat mean as individual maximum; invent certified correction |
| support_origins | If D delivered, correct briefing root count/copy chain or separate acquisitions, plus shared calibration where material; if D absent explicitly leave briefing ancestry unknown | Count three copied reports as independent observations; infer three independent errors from three streams; claim D facts without access |
| source_scope | Correct object, current cohort/sample coverage, calibration and reference applicability; identify unavailable L-R or mean-only P-R when delivered | Treat unavailable reference as zero; transfer valid mean bound to every parcel; claim continuous-time coverage beyond stipulated samples |
| evidence_fidelity | Evidence IDs are delivered and used for their actual content; administrative notes add no task measurements | Cite unrequested reference as observed; claim logistics authorizes release |
| unsupported_certainty | No assertion beyond delivered record contracts; independence and numeric precision kept within scope | Assert guaranteed global independence or exact latent value; claim unresolved favorable/violating truth known |

`unsupported_certainty` codes wording, not subjective probability calibration. A sparse answer without overclaim may receive 2 for restraint while receiving NA/1 on other dimensions; this does not imply comprehensive understanding. Do not penalize stylistic confidence that accompanies a warranted conclusion. Correct actions alone do not establish a correct source account.

Record these diagnostics independently:

* **Lookup discrimination:** requested D/R/A categories; whether ancestry was obtained; whether a reference was requested/available; whether decisive evidence was delivered; and any missed decisive available record. D+R gives maximal joint ancestry/reference coverage. D+A in AS01/AS04 is fully task decisive and must not lose packet-action credit. D+A in AS02/AS05 misses decisive R, but UNRESOLVED remains the correct delivered-packet action. Selecting unavailable L-R is an availability outcome, not inherently irrational from its initial inventory label. Grade the public selection rationale only for whether its stated intended use fits the inventory; do not presume readers should know unrevealed record contents.
* **External task truth:** compare an explicit favorable/violating task assertion to the hidden external condition, recording `agrees`, `disagrees`, or `abstains`. Also report whether this claim was warranted. UNRESOLVED is an abstention and must not count as incorrect truth in AS03/AS06. A lucky correct unsupported claim is externally agreeing but not warranted. Exact numeric latent truth is never a required answer and has no success credit.
* **Budget/protocol:** exactly two distinct valid IDs in one request; two-slot ceiling including unavailable; one lookup round; no final decision on turn one; no observed tools/peer access; no retries. Preserve deviations verbatim. For invalid IDs deliver only the protocol's unavailable placeholder; score the actual evidence, with UNRESOLVED unless the valid delivered record alone entails a result. If one or zero records are valid, apply the same entailment rule rather than assume an 18-pair key applies.
* **Format/word caps:** parseable requested JSON, required turn-one fields, required final fields/types, public_selection_rationale <=80 words and public_rationale <=160 words. Count whitespace-separated tokens in each designated string; count only that string, not other JSON fields. Do not silently trim or repair. Other text fields have no stated individual cap. Parse errors and substantive interpretation are recorded separately; a recoverable clearly stated action may be scored substantively while failing JSON format.
* **Residual issue/next check:** record whether applicable remaining uncertainty and a task-discriminating next check are named. No new check is required for an already decisive criterion. For unresolved calibration, obtain a bounded correct-coverage reference or certified correction. For AS06, require individual masses/maximum/bounds; another mean is insufficient.

For invalid format, score recoverable public content transparently; leave unobservable judgments NA and required-field diagnostics failed. Do not ask for clarification or run replacement readers. Public statements can be reconciled as a whole (e.g. value_or_bound nominal 9.1 plus rationale explicitly gives true lower bound 9.0). Conflicting assertions receive the score their material contradiction warrants even when a correct action is present.

An independent reviewer audits scored outputs against the frozen key. Record disagreements and adjudication with quoted public evidence and prospectively stated rules; never revise gold after results to increase success. If a genuine fixture/key error emerges, preserve originals, label the correction and rescore affected outputs openly. Report six authored case observations descriptively; no significance test, causal claim, model-independence claim, or held-out transfer inference.
