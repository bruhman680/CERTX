# Frozen contact protocol

Version 1, 2026-10-31. Scope: optional read-only query of explicit caller-declared DAG ancestry. Existing six-station registry and its receipts remain unchanged. No inference, paid services, training, navigation edits or external publication.

An edge points from child to parent. Ancestors include the node itself. For the nonempty query set Q, intersect all reachable ancestor sets C, then return every c in C for which no distinct d in C has c as an ancestor. Output is sorted by node ID only for stable presentation. This is maximality under declared ancestry, not greatest depth. Multiple results and empty results are valid. For more than two query nodes this is an intersection over all nodes (akin to Git octopus semantics), not Git's default hypothetical merge semantics.

Inputs have exactly graph_id, edge_semantics, nodes, query. Nodes have id, parents, optional artifact {path, sha256}. IDs are unique nonempty strings. Duplicate parents or query nodes, unknown parents or query nodes, empty query, cycles in any component, extra schema fields, more than 256 nodes, invalid paths/hashes and mismatched bytes reject. Manifest and each bound artifact are limited to one MiB. Paths must resolve under the declared local root, including symlinks. The strict existing JSON loader rejects duplicate object keys and nonfinite constants. This operates in a trusted local workspace, not a hostile concurrent filesystem.

Before running authored tests or the real query: write protocol, test_ancestry.py, manifest.json and FREEZE.json with exact SHA256 of inputs and implementation dependencies. Preserve the first test output even if it fails. Do not revise frozen files silently. Then run the authored suite, store output and machine-readable exit status; run the frozen real manifest once and save RESULT.json. Verify freeze hashes after the run. Any failure or revised run must remain distinguishable in artifacts.

Authored expected cases: rooted tree; two incomparable LCAs; unequal-depth shortcut trap retaining both incomparable results; transitive ancestor removal; self/single query; disconnected roots; self/two-node/disconnected cycles; unknown parent/query; duplicates/schema/empty query; artifact success/hash mismatch/malformed hash/traversal/absolute/symlink escape/missing file; strict JSON; node cap. These cases establish scoped implementation behavior, not external graph completeness or scientific validity.

Real contact: four byte-bound nodes from the six-station registry's LoRA pilot. Two DERIVATION records literally name the same raw_parent_sha256 and key_parent_sha256; edges are those two recorded parent declarations for each record. The shared RAW_OUTPUTS and KEYS files are terminal nodes only in this partial graph. We query the records themselves, not entire station evidence or model histories. Predeclared expectation: maximal common ancestors are shared-key-parent and shared-raw-parent; no other common nodes. The graph does not infer a KEY_SUBSET→KEYS edge merely from flat shared registry hashes. No causal independence, truth, confidence, pooled score or model quality claim follows.
