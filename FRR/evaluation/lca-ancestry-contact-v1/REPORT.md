# Result and scope

The optional declared-DAG tool returned both `shared-key-parent` and `shared-raw-parent` as maximal common ancestors of the LoRA original/adapted test derivation records. This matches the predeclared expectation. The graph has four byte-bound nodes and four parent edges; it represents only the literal raw_parent_sha256 and key_parent_sha256 declarations in the two DERIVATION files.

The first authored test run passed all 12 test methods, including several parameterized rejection cases. It covers tree ancestry, two incomparable answers, an unequal-depth shortcut trap, removal of higher transitive common ancestors, self/single-node semantics, disjoint roots, cycles in disconnected components, unknown references, duplicates/schema, node cap, strict JSON and local artifact hash/path/symlink failures. TEST_INITIAL.txt preserves the first output and TEST_STATUS.json the exit status. The first real query completed with exit 0; RESULT.json and QUERY_STATUS.json preserve its output/status. Freeze verification is in CHECKS.json. There were no failed implementation test runs; source fetch failures remain in sources/FETCH_LOG.json.

Ancestry here means declared parent reachability, including self. Both returned nodes are incomparable in the declared partial graph; no depth ranking or single arbitrary selection was used. Their terminal status does not establish that the real artifacts have no ancestors. The existing six-station registry manifest, index and receipts were not changed by this feature. Merely finding shared hashes in that registry would not justify fabricating a complete graph.

Byte binding confirms that the supplied files matched the declared SHA256 at query time in this trusted local workspace. It does not authenticate declarations or runtime, prove source truth or causal independence, or supply a probability, confidence estimate, model competence result or pooled score. Completeness and meaning of edges remain the caller's responsibility. Omitting or adding graph nodes/edges may change the answers. Missing common ancestors in this graph cannot establish independence.

This is a small bounded diagnostic, not an external benchmark or production-scale graph service. It uses standard-library set reachability over at most 256 nodes, and existing strict JSON/path/hash helpers. It adds no dependency, model call, training or paid service. No navigation or external publishing changes were made in this contact.
