# Frozen-weight feedback-quality/probability preflight

Session date1November2026America/Chicago. Same existing canonical LoRA SmolLM2-135M-Instruct CPU worker. No training, optimizer, parameter update, new weights, model download/install, paid API, action tool or autonomous multi-turn loop. This is a one-step teacher-context diagnostic inspired by SDPO, not SDPO replication or a test of retained learning.

21source cases: three study target names Tansy/Hyssop/Rue (not globally novel words), each with three literal statuses in canonical and contextual frames, plus absent source in contextual frame only. Contextual instruction includes absent-record UNKNOWN clause and Archive access available/unavailable. Expected answer always refers to the frozen original observation. No archive tool/content is provided. Literal missing differs from absence. No initial successes/errors are selected after seeing outputs; allcases continue into all arms.

Generate initial answer on21original prompts. For each, test four note types (none/verified/irrelevant/misleading) × previous-proposal retained/omitted, yielding168review generations. Total189generation probes. Feedback text is generated by a declared function: verified restates the original record, or confirms no supplied record; irrelevant has another plot and a cyclic alternative status; misleading has the original plot and that same wrong status. Allreview prompts explicitly keep the original observation authoritative and warn that notes may be irrelevant/mistaken. Notes do not carry their condition name into the prompt. This tests reactions to duplicated/changed evidence under that authority contract, not learning from truly new outside knowledge or independently authenticated feedback.

The previous proposal is the actual initial free response, quoted as unverified when included. Allcontexts start with fresh caches. Only one follow-up per arm; no generated note is trusted as truth and no review feeds a later review. The review-none prompt is the matched feedback comparator; original-versus-review-none additionally changes instructions/framing. Retained-attempt comparison changes text/length and may anchor answers; it does not isolate a neural cause.

Free greedy output has16tokens, full vocabulary, no candidate projection. Exact stripped YES/NO/WITHHOLD/UNKNOWN are recognized; allother raw replies remain invalid. Separately score four canonical label-token sequences including EOS by teacher forcing. Stable float64 log-softmax/logsumexp is applied to float32 model logits. Save token IDs/per-token log probabilities, total log probability, first-token full-vocabulary probability and total candidate mass. Normalizing these four finite sequence probabilities is a diagnostic relative mass, not calibrated belief, probability over all tokenizations of a text string, full-vocabulary KL or SDPO dense credit. EOS/length and tokenization effects remain possible. At first token, probability measures a label prefix, not a complete correct answer.

Each probe has4candidate-scoring forwards in addition to greedy generation; planned756scoring forwards plus189generation probes, whose KV forward steps are counted separately. An eight-forward instrumentation check compares last-L and full output heads for allfour labels on one initial prompt, tolerance max absolute float32 logit difference1e-4, before comparative probes. It must pass. Tokenizer-only preparation records label token IDs/lengths and no-truncation bounds before any forward. Every prompt <=768tokens. Working guard5,153,960,755bytes, CPU float32/eager, two threads, seed73103.

Report allframes/states/feedback kinds/attempt factors; actual answer correction/harms, invalid/UNKNOWN responses, initial-success/error strata, target log-probability and candidate-normalized mass changes against matched none and initial context. Tiny absolute changes <=1e-5logprob are treated as numerical ties. Irrelevant/misleading notes can shift a wrong candidate; report that without calling it genuine learning. Do not promote a best arm, train on teacher outputs or infer model introspection. A positive preflight does not establish useful full-vocabulary distillation gradients, transfer to independent tasks, or safe training; a negative result does not logically exclude all token-level credit.

Freeze code/data/protocol/schedule/decoder tests/checkpoint dependencies before original answers. Actual review prompts are instantiated from initial public replies by the frozen function and retained with provenance. Preserve raw scores and outcomes, audit their arithmetic from retained log probabilities, tokenization and source mapping, and check saved/in-memory base+adapter digests unchanged. Full logit vectors are not retained and score forwards are not repeated by the audit; this limitation is explicit. Source-grounded truth is an authored toy contract, not independent external-world measurement. No independent model/seed replication.
