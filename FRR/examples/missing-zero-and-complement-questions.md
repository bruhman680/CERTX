# Missing, known zero and a calculation's domain are different

[FG/MF/CP](../evaluation/count-presence-polarity-v1/REPORT.md) supplies the observed examples. This is optional guidance, not an automatic language parser or a model repair.

| Source | Independent-soil count | Calculation implication |
|---|---|---|
| There are18independentlysampledsoils;6observations each | Known18 | A declared formula can receive18after its other inputs/roles are validated |
| Soil count was not recorded;18observations per soil | Missing |18belongs to another field; no point count is warranted |
| There are0independentlysampledsoils;9observations per soil planned, none collected | Known0 | Source count is recorded; an estimator formula dividing by k/N is outside its domain with no data |

Do not convert missing to0or use an adjacent field's number. Do not label a known0as an unrecorded count simply because observations were not collected. These states can all lead to withholding a calculation through different stages; the same withholding label does not validate the stated reason.

If two questions are declared logical complements for the same target/scope, identical binary answers flag inconsistency. Complementary answers can still be wrong: for a source with a missing count, YES-to-recorded and NO-to-unrecorded are complementary and false. This is a logical illustration, not an additional model test. Source evidence remains necessary. Do not apply this rule to arbitrary questions whose relation/scope has not been established.

In the observed test, both question answers were correct for3/8sources; the other5gaveYESbothways. Correct labels from separate prompts do not establish one coherent extraction or an autonomous verifier. The earlier7/7readiness condition failed at5/7and remains failed; no arithmetic was run afterward. A new source-bound witness would require its own declared grammar, interface, negative cases and prospective evaluation before adoption.
