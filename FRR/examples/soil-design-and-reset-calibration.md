# Label the experimental design as well as the answer

[SD-C1/2/3](../evaluation/soil-design-three-cycle-v1/REPORT.md) is a toy witness for this optional practice.

When a conclusion depends on repeated observations or a reset, record:

1. Target: a population mean, this particular environment's rate, a predictive law, or causal location?
2. Sampling: how many independent latent-condition draws, with how many observations per draw? Which observers share a condition?
3. Model scope: which alternatives are allowed, and which output features can distinguish them?
4. Intervention: what is changed, what remains fixed, and how is effectiveness known or bounded? Was the first event observed or forced?
5. Residual uncertainty: a point estimate, a feasible set, or an unresolved model assumption? Does the action remain warranted across it?

In the authored example, 64 observations from one soil yield population-mean variance .034; 64 independently sampled soils yield .0025. Those designs ask about the same population average but are not interchangeable for learning within-soil structure. A beta soil and a two-point soil match all one- and two-observation laws; longer grouped records distinguish their named laws.

Reset readouts (.160,.128,.088) are compatible with internal-carrier run fractions .25, .40, or .50 under different efficacies. With efficacy otherwise unknown in [0,1], the full feasible interval is [.20,.55] under this particular no-cross-effect model. A reset name supplies no efficacy evidence. Conversely, the interval can collapse for decisive readouts; preserve what the actual constraints establish.

This checklist is not an automatic validator, a reason to erase model memory, or empirical evidence of improved agent reasoning. Source hashes bind bytes, not these statistical assumptions.
