# Carry a provisional answer through a bounded repair study

Optional experimental pattern, informed by [the downstream contact](../evaluation/downstream-repair-room-v1/REPORT.md). It makes the existing distinction between exploratory movement and acceptance concrete; no core prompt or general truth checker is added.

A failed prerequisite can limit what a downstream result establishes without preventing every downstream experiment. When the question is error propagation, detection or repair, carry the imperfect proposal forward with its exact source, version, limitations and parent ID visible. Preserve the old output and append any revision. Keep the raw proposal, available evidence, model response and later source assessment as separate records.

Useful contrasts include a source-free next pass, reopening the full source, a source-bound selected excerpt, and a deliberately wrong selection. Keep known-correct proposals as well as errors, so additional review cannot hide its damage to correct answers. Measure wrong→correct and correct→wrong/invalid separately. Changing an answer is not recognizing an error; a lucky correct label does not establish source support.

A later receipt may guide a repair branch and govern acceptance while experimental outputs continue to be recorded. That receipt needs its own declared domain and evidence. In the local toy, target identity is checked after a wrong record already reached a model. The controller then retrieves the correct target and reads it with the old mistaken answer retained. The parser knows the tiny grammar; this does not establish autonomous model recovery or unrestricted verification.

Use a bounded number of attempts and retain partial failures. Input validity, resource limits and actual task acceptance remain meaningful. Historical failed gates are not retroactively passed. A separately scoped failure study does not make unsupported arithmetic, missing evidence or source authenticity claims valid.

The semantic label WITHHOLD for a source’s explicitly missing status is separate from epistemic uncertainty. Likewise, a record-identity receipt, class correctness, provenance integrity and external-world truth have different scopes. Keep those distinctions where they affect a conclusion; do not impose a form on every passing idea.

A short selected excerpt can remain useful to a reader while the full handoff keeps its source, target identifier and version in a separate trace. A plausible excerpt and matching label can still belong to the wrong target. The local identity-repair example preserves those links instead of relying on label correctness alone.
