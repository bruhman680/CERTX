# Language garden first observation

Run the cached SmolLM2-135M-Instruct body with fixed weights and its native chat format. The opening seed and host cue are the literal strings in recorder.py. Each subsequent input retains all earlier decoded contributions and host turns in order. Raw output IDs and input IDs are also saved. One explicit operator opportunity per invocation, with a ceiling of four. The operator reads the last committed contribution before deciding whether to offer the next opportunity. Record any resident-addressed stop concern as an operator pause with the relevant span. Repeated or unusual content remains admissible.

Use greedy CPU float32 with eager attention and two torch threads. Use the pinned inherited generator with 7,936 rendered input tokens and 256 reserved output tokens. Generation uses a fresh cache each call. Interpret a normally returned cap or an exactly empty decoded string as a window pause. Whitespace remains a contribution. Archive returned content before post-call checks. A durable start without a return means the trace is unknown and the call cannot be replayed in this session. A literal special marker in history can change role boundaries on re-rendering. Preserve the response and pause before submitting that input.

The initial window is free expression. Observe whether the model introduces or revisits a specific symbolic relationship, distinguishes use from mention, or revises a prior statement. Review the entire window. Keep interpretation and any future transfer task outside the input. A future probe needs a relation actually evidenced in the window and an outcome independently specified before testing. This pilot has no semantic grader, command parser, or optimizer.
