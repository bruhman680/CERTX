# Word versus symbol on the reserved repeat rows

Replay all twelve reserved rows from cycle 10 of the ten-cycle repeat run in its original case order. For each prompt replace exactly “Which symbol appears twice in this row?” with “Which word appears twice in this row?”. Retain every other character, including “Reply with the symbol only.” This isolates the change in the question. Record actual tokenizer lengths. Use the same fixed SmolLM2-135M-Instruct CPU runtime, native system message, original preface, greedy decoder and 256-token cap. Each new call opens an independent one-turn context with no feedback. The pinned original replies provide the comparison arm.

Compute exact and recognizable correct answers with the original frozen scorer. Report per-row gains and losses, changes to recognizable in-row versus out-of-row replies, stop reasons and all three fixed-position reference scores. Report, within each lexical family, which of the two near-neighbor pairs that should switch the answer actually got both answers right. The three shapes are AAB, ABA and ABB. Every lexical family contains all three. This is a paired wording experiment on a reused panel, so a gain here would need a separate replication before a stronger claim.
