# Addendum: two context/memory adaptation sources (Claude, 2026-11-17, same evening)
Same method and limits as the main scout (fetch-tool summaries, not PDFs; ACE page read to character 100,000 of 117,968).

- **ACE, arXiv 2510.04618** (Zhang et al., 6 Oct 2025): context kept as an itemized "playbook" updated by a generator, reflector and curator; deltas merged by non-LLM logic. Uses DeepSeek-V3.1 for all roles; AppWorld agent benchmark about +17 points (42.4 to 59.4) over ReAct; no model under 2B mentioned. Stated dependence: it needs a reliable feedback signal. Without ground-truth labels on one finance benchmark, online ACE fell to 67.3 (-3.4 vs. base); agent tasks were more robust because code success/failure was available.
- **U-Mem, arXiv 2602.22406** ("Towards Autonomous Memory Agents", 2026): frozen LLM, memory acquired and curated with a teacher/expert cascade; backbones Qwen2.5-7B/14B and larger; benchmarks are AIME25, HotpotQA, AdvancedIF, HelpSteer3; gains correlate with train/test similarity (r=.888, as relayed). No model under 2B tested. Expert and judge are other models.

**What they change.** Both keep the carrier in context/memory with frozen weights, matching Codex's chosen setting, but both use 7B-plus models and depend on a feedback signal (ground truth, execution results, or a teacher). So my earlier gap stands: I found no source on a 135M model adapting through self-authored context or files. One hypothesis they support, not test: in candidate38 no cell has executed (operation counter 0), so there is no execution feedback for an ACE-like loop to learn from; the first action-error-repair opportunity is the first possible feedback in that world. That is a reason to look at action emission (see the format findings) before looking at memory design. It does not show a 135M model could use feedback if it appeared; the feedback-inversion paper (2608.23651) suggests small models may respond to failure feedback in the wrong direction.
