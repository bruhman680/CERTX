The derivative is gamma+(w*beta/2)*sech²(beta*z/2). For the nonnegative parameters used, its global bound is gamma+w*beta/2. The three controls bound it by .95, .9, and .9 respectively, so each map contracts toward its fixed point zero. The original map has derivative 1.1 at zero: zero is locally unstable, though it remains exactly fixed without perturbation. Thus the numerical contraction has a relevant mathematical bound, and the rebound has a specific source in the restored transition rule. This is stronger than inferring stability from a small residual alone.

## Transformer: protocol status

The script compares contexts with swapped assignments and identical suffixes. It measures raw logit contrast separately from downstream temperature-scaled probabilities and compares cached versus full evaluation of the same complete prefix. These are useful controls, with distinct conclusions.

The contexts contain the same word counts. Token lengths are asserted at runtime, but token-ID histograms are not checked; assert those too if token-level lexical balance is part of the claim. A model may also respond to immediate examples or positional associations rather than infer an abstract rule. Counterbalance assignment order, labels, repetitions, and task instances; evaluate on held-out assignments.

`restored_blue` is identical to `blue_rule` and every call starts a fresh forward route. This checks deterministic replay consistency. It does not reset a previously altered agent while retaining a separately changed environment, or demonstrate history dependence after the complete conditioning input is fixed. Context can be treated as a carrier relative to reset generation, but the focal-system boundary must be explicit. Cache equivalence tests an implementation route, not independent evidence of wake formation.

Raw logits do not change when the script subsequently applies sampling temperature; this is guaranteed by where temperature enters the construction. It is useful implementation separation, not a risky empirical confirmation. No effect size or model accuracy has been measured here.
