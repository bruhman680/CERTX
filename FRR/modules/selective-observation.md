# Selective observation, complete evidence

Optional external review habit, implemented in evaluation/selective-observation-v1/observer.py. Keep raw records and provenance; summarize routine windows; focus close review on versioned change flags, with a small deterministic quiet sample. Always run integrity/resource/feedback/history checks on every row. All boundary/instrumentation failures remain mandatory review items.

Use current handoff and ATTENTION.md as working entry points. Fetch exact indexed records when needed rather than loading whole historical transcripts. Store historical navigation as linked archives, not repeated inline content in the current map. Keep overflow flags available; an unreviewed row is not declared irrelevant.

Flags are provisional attention signals, not verified phases, novelty, sophistication, health or improvements. New words/longer text can reflect imitation or failure. Quiet samples can expose blind spots, but no finite sample guarantees completeness. Criteria/threshold/selection revisions need versioned provenance; don't rewrite prior measurements.

External attention selection does not trim the model's notebook or change its memory policy. Model input limits, history views and resource expansions are separate experimental decisions. See the study report for tested scope, failures and exact receipts.
