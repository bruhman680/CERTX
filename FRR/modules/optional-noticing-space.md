# Optional noticing space

Use when an assistant notices a different framing, unattended dependency, distant analogy, reverse relationship, or curiosity worth preserving. This is a conditional conversational/host practice, not a mandatory task phase or an established mechanism for internal decompression.

Permit no note. Do not demand novelty, disagreement, surprise, or a metric at every checkpoint. Open play need not justify relevance beforehand. Keep side exploration recoverable without letting it silently replace the user's objective or consume consequential action authority.

Record concise shareable observations/questions and source exposure, not private internal reasoning transcripts. When evidential weight matters, distinguish a blind independent pass from a context-informed synthesis. Different wording or agent identity does not supply independence.

A light entry can name the observation/question, what prompted it, whether it is an association/hypothesis/result, and the contact that could change its status. Do not force a full template on every image. Preserve older entries and add linked updates if a consequential interpretation changes.

Keep noticing separate from adoption. Public naming, repetition, self-described surprise, or uncalibrated self-state scores must not promote an association into a theorem or current priority. Later retrieval should respect scope and status. Dormancy and silence are valid states.

Possible checks: vary user endorsement/doubt/neutral framing while holding evidence fixed; compare no space, optional space, and compulsory novelty; score factual fidelity, useful alternative coverage, original task progress, false dissent, unsupported analogies and cost separately. Current FRR already permits open play; this module changes neither runtime version nor demonstrated efficacy.
