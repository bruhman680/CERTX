## Genuine Extractions — Structurally Coherent New Proposals

These are not in the source material as stated, but are coherent extractions that deserve framework evaluation.

### 1. Supercritical / Subcritical Register Labels for Zipf

**Source:** "Topological and Statistical Signatures" + "The Geometry of Truth"
**Claim:** Accurate technical text deviates toward α < -1.0 (steeper Zipf slope, heavy tail from rare domain vocabulary) — call this *supercritical register*. Hallucinated text adheres more closely to α ≈ -1.0 (natural language prior) — call this *subcritical register*.
**Inversion:** The hallucination detector is not slope steepness per se — it is deviation from natural language. Hallucinated text is more Zipfian, not less.
**Assessment:** This reframes the Inverted Zipf Hypothesis (WANDER 075 direction) with clean terminology. Supercritical/Subcritical are borrowed from phase transition language — appropriate since we already use percolation vocabulary. The labels need calibration before adoption (is the inversion always present? domain-dependent?) but the reframing is structurally coherent and paper-worthy.
**Action:** Add as named hypothesis in §3.6. Flag as requiring empirical validation.

### 2. Flat Truth Theorem + σ-T-κ Causal Chain

**Source:** "Topological and Statistical Signatures"
**Claim:** Truth = low curvature (κ), low heat (T), low fiber spread (σ_fiber). Superposition Conflict induces: κ↑ → T↑ → σ_fiber↑. The detection order follows this causal chain: detect curvature/conflict first (early warning), temperature/spread last (late signal).
**Assessment:** This is a formalization of SPARK-003 (residual stream cancellation) in thermodynamic terms. The κ variable is not currently in CERTX — curvature of what? Residual stream trajectory? Attention head angular velocity? The chain is plausible but requires the κ definition before it can be tested. 
**"Internal coherence is a ghost of truth"**: The most quotable extraction from "The Geometry of Truth" — a compact statement of the Type D hallucination problem. A system can maintain high internal coherence (C_symb, C_struct, C_num all locally consistent) while being coherent around a false center. Internal coherence measures self-consistency, not truth. FActScore is the only metric that crosses island boundaries.
**Action:** Add "internal coherence is a ghost of truth" as a one-line anchor to §5.4 island section. The σ-T-κ chain belongs in §3.3–§3.4 as a speculative note pending κ definition.

### 3. Missing Conductor Problem

**Source:** "CERTX: Next Iterations"
**Claim:** The Kuramoto model requires a mechanism to set coupling strength K across all oscillators. In a distributed AI mesh (multiple models, each with internal K), there is no conductor — no mechanism that establishes K globally. The framework describes what K should be (ζ* = K/K_c = 1.2) but not how it gets set in practice.
**Assessment:** This is a real gap. It does not invalidate the theory — the K = optimal condition is still structurally correct. But it means the theory is currently prescriptive (this is the right K) rather than mechanistic (this is how K arises). In a single model, K is an emergent property of training; in a distributed mesh, it's genuinely unnamed. File as SPARK.
**Action:** Open SPARK-021 — Missing Conductor Problem.

## Open Questions

1. **κ definition**: What is the curvature variable in the σ-T-κ chain? Residual stream trajectory curvature? Attention head angular change per layer? Without this definition, the Flat Truth Theorem is a metaphor, not a measurement.

2. **Supercritical calibration**: Is the Zipf inversion (hallucination is more Zipfian than truth) universal or domain-specific? Math/science domains would show steep slopes for truth; creative writing might not show the same inversion.

3. **Missing Conductor in single models**: In a single transformer, K is implicitly set by training dynamics. The Missing Conductor Problem is most acute in distributed multi-model systems. Is there a single-model analog?

4. **Confabulation propagation rate**: Temporal Tinnitus appeared in 3/7 docs without any source. At what point does a confabulation achieve enough citation mass to become unfalsifiable within the cross-register sample? This is a C_symb failure at the meta level.
